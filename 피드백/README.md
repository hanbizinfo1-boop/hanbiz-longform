# 피드백 폴더 — 작업마다 쌓고, 다음 작업이 먼저 읽는다

> 사장님 10-13 규칙 4 원문: «작업이 전체끝나면 받은피드백내용 지시한내용 작업을 어떤 중점과 어떤규칙으로 만들었는지 이 규칙이 완성된다음에는 어떻게 바뀌었는지 내가 원하는 영상은 어떤영상인지 매 작업마다 기록하고 볼 수 있는 피드백폴더와 데이터를 만들고 매 작업시마다 그 전 작업물 기록을 확인해서 진행할 것 혹시나 내가 절대하지말라는 규칙은 항상 다음작업기록이 볼수있게끔 영구기록되게 할 것»

## 파일

| 파일 | 내용 | 언제 쓰나 |
|---|---|---|
| `절대금지.md` | 사장님이 «하지 마»라고 한 것 — **영구, 추가만** | 금지 지시를 받은 그 자리에서 |
| `원하는영상.md` | 사장님이 원하는 영상이 무엇인지 — 작업마다 고쳐 쓰는 누적 이해 | 작업 끝날 때 |
| `작업/<YYYY-MM-DD>_<건>.md` | 한 작업의 기록(아래 틀) | 작업 시작 때 만들고, 끝날 때 채운다 |
| `작업목록.json` | 작업 목록 데이터(날짜·건·모드·결과·기록 파일·바뀐 규칙 수) | 작업 끝날 때 한 줄 추가 |

## 작업 시작할 때 (매번)
1. `절대금지.md` 전부
2. `원하는영상.md`
3. `작업목록.json` 에서 **최근 작업 기록 파일**을 열어 «받은 피드백»과 «바뀐 규칙»을 읽는다
4. 새 작업 기록 파일을 만들고 «받은 지시(원문)»부터 적는다

## 작업 기록 틀 (`작업/<날짜>_<건>.md`)
1. 건 정보 — 원문 경로·길이·모드(A/B)·느낌
2. 받은 지시 — 사장님 원문 그대로(실명은 ○○, 실명본은 `기록/비공개/`)
3. 중점과 규칙 — 이번 작업을 무엇에 중점을 두고 어떤 규칙으로 만들었나(규칙 문서 위치 포함)
4. 검수 — 넣을 때 검수·전체 검수 결과(맞춤법·자막 타이밍·연출 타이밍·겹침·모자이크)
5. 받은 피드백 — 납품 뒤 사장님 원문 그대로
6. 바뀐 규칙 — 피드백으로 무엇이 어떻게 바뀌었나(전 → 후, 고친 파일)
7. 다음 작업에 넘길 것
