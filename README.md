# 한비즈 영상 제작 플레이북 — 직원 공유용

한비즈에서 Claude Code 로 롱폼 영상을 기획하고 만드는 방법을 **숨김없이 전부** 담은 정리본입니다.
대본 쓰는 법, 연출 규칙, 효과음 고르는 법, 썸네일, 검사 도구, 사장님이 반려한 것과 통과시킨 것까지 들어 있습니다.
이 저장소를 받아 Claude Code 로 열면 같은 규칙과 도구로 바로 작업을 시작할 수 있습니다.

> 실제로 일하는 저장소를 그대로 공개했습니다. 고객·업체 실명과 전화번호는 기록까지 ○○ · 010-0000-0000 으로 바꿨고, 계정 정보와 영상·음원 원본은 **없습니다**(빠진 것은 아래 6장).

---

## 1. 이게 뭔가요

| 하는 일 | 결과물 |
|---|---|
| **A. 얹을 것만** — 사장님이 «이 구간에 이런 연출»을 지정 | 장면 mp4 + 효과음 XML + 미리보기 → 프리미어에 얹음 |
| **B. 자동 연출** — 원문 한 편을 통째로 맡김 | 완성본 mp4 + 검수표 + 백업 XML |
| **C. 채널 콘텐츠** — 사람 출연 없이 대본 + 목소리 + 연출로 유튜브 채널 영상 | 주제 → 제목·썸네일 → 대본 → 녹음 → 연출표 → 완성본 |

규격: 가로 1920×1080, 59.94fps. 컷과 자막은 사람이(사장님) 정하고, Claude 는 무음편집·연출·효과음·검사를 맡습니다.

## 2. 준비물 (한 번만)

1. **Claude Code** 설치 → 이 저장소를 받은 폴더에서 `claude` 실행
2. **Python 3.11+** 와 패키지: `pip install numpy pillow opencv-python`
   (받아쓰기를 쓰면 `torch`·whisper 계열도 필요 — `tools/transcribe_words.py` 머리말 참고)
3. **ffmpeg** (PATH 에 등록), **Chrome**(카드·디자인 장면 캡처), 필요하면 **Blender**
4. **Codex CLI** (`npm i -g @openai/codex` → `codex login`) — 이미지 생성 전담, 추가 과금 없음
5. `setup/claude-home/` 안의 파일을 내 홈 폴더 `~/.claude/` 에 복사
   - `scripts/codex-run.ps1` — Codex 호출기
   - `agents/codex-luna.md` · `agents/sonnet-5.md` — 서브에이전트 정의
   - `CLAUDE.md` — 모든 세션 공통 규칙(이미 내 것이 있으면 내용만 합치기)
   - 복사한 뒤 Claude Code 를 다시 시작
6. **경로 맞추기**: `tools/config.py` 한 곳에 모든 경로가 있습니다. 내 컴퓨터에 맞게 고치거나 환경변수(`HANBIZ_SFX_LIB` 등)로 덮어씁니다.
7. **역할 정하기**: `핸드오프/역할.json` 의 `"기획"` 값을 기획할 컴퓨터 이름(`hostname`)으로 바꿉니다.

## 3. 시작하는 법 — 말 한마디로

Claude Code 를 이 폴더에서 열고 아래처럼 말하면 됩니다. Claude 가 `CLAUDE.md` 의 «읽는 순서»대로 규칙을 먼저 읽고 시작합니다.

| 이렇게 말하면 | 이런 일이 일어납니다 |
|---|---|
| «상태 봐줘» | `python tools/handoff.py 상태` — 지금 내 차례인 건 |
| «3편 주제부터 추천해줘» | 최근 90일 상위 영상 근거로 주제 후보 (`study/trend-1014.md` 방식) |
| «제목이랑 썸네일부터 뽑자» | 제목 후보 + Codex 썸네일 시안 (`study/thumb-1015.md`) |
| «대본 써줘» | 대본 규칙 정독 → 작성 → `script_check.py` 통과까지 |
| «기획해 — 원문 ○○ / 느낌 ○○» | 새 건 폴더 + 지시서 + 연출표 |
| «확인하고 작업해» (제작 PC) | 받기 → 분석/제작 → 검수 2번 → 납품 → 결과 기록 |
| «결과 확인해» | 피드백을 규칙 문서에 반영 |

컴퓨터 한 대로 해도 됩니다. 두 대면 기획 PC 와 제작 PC 로 나눠 GitHub 로 주고받습니다(`핸드오프/README.md`).

## 4. 채널 영상 한 편 만드는 순서 (C 모드)

1. **주제** — 감이 아니라 데이터로. 최근 90일, 비슷한 채널 상위 영상만 본다.
2. **제목 · 썸네일 먼저** — 대본보다 먼저 정한다. 썸네일은 **올린 뒤에 바꾸지 않는다.**
3. **대본** — 쓰기 전에 `study/bisa-script-1014.md` 와 `study/gupd-1028.md` 전문을 읽는다.
   쓰고 나서 `python .claude/skills/longform/scripts/script_check.py <대본> --save` → **ERROR 0** 이 아니면 다음 단계로 안 간다.
4. **녹음** — 대본은 녹음 원고다. 읽을 말만, 한 줄에 한 숨.
5. **연출표** — 장면마다 배경·매체·구도가 달라야 한다. `scene_check.py <연출표>` ERROR 0.
6. **제작** — Codex 이미지 · HTML/클로드 디자인 · compose · Blender. 애프터이펙트 없이.
7. **검수 두 번** — 장면 넣을 때 한 번, 완성본 전체 한 번(맞춤법 · 자막 타이밍 · 효과음 타이밍 · 겹침 · 모자이크).
8. **설명란 · 고정 댓글** — `study/channel-setup-1016.md` 틀대로.

## 5. 우리가 원하는 영상 (요약 — 전문은 `피드백/원하는영상.md`)

**화면**
- 그 말이 **실제로 일어나는 자리**를 보여 준다. 설정 화면에 값을 넣는 장면, 실제 정산서, 가게 안 — 말과 같은 장소.
- 진짜 이미지만. 도형으로 사물을 흉내 내지 않는다.
- 화면 글은 개념어 몇 단어. **말을 그대로 글로 따라 쓰지 않는다.**
- 같은 배경·분위기·구도가 이어지면 «AI로 찍어 낸 느낌»이 난다. 장면마다 다르게.
- 밋밋하게 두지 않는다. 글이 뜰 때 강조 포인트(커서·타자·테두리 번짐).

**대본**
- 첫 30초 안에 첫 항목. 인사·예고로 시간 끌지 않는다.
- 통념 뒤집기로 시작 → 증거 → 누구를 위한 영상인지 → 항목 → «오늘 딱 하나» → 공유 부탁 → 인사.
- 호칭은 무조건 **«대표님»**. «남는 돈» 대신 **«수익»**. 판매 멘트 없음. 다음 편 약속 없음.
- 지어낸 상담 사례를 실제처럼 말하지 않는다. 플랫폼 약관에 걸릴 수 있는 방법은 권하지 않는다.
- 예시 업종은 앞 세 편과 겹치지 않게.

**소리**
- 효과음은 그래픽에 붙고, 뜻(긍정·부정·중립)과 그림에 맞고, 자연 길이 그대로. 같은 소리 연달아 금지.

**절대 하지 않는 것** — `피드백/절대금지.md` 를 꼭 처음부터 끝까지 읽으세요. 예: 말풍선, 흔들리는 연출, 까만 화면 전환, 빵빠레, 이모지, 단색 배경판, 같은 트랜지션 연속.

## 6. 주의사항

- **유료 생성(Kling · 힉스필드)은 호출마다 돈이 나갑니다.** 시험 삼아 돌리지 않습니다. 이미지는 전부 Codex 로 먼저, 유료는 영상화·업스케일에만, 장면당 한 건.
- **개인정보**: 업체명은 ○○, 전화번호는 010-0000-0000. 녹화 화면에 나오는 실제 정보는 모자이크(`tools/mosaic_scan.py` → `mosaic_render.py`). 실명 목록은 `기록/비공개/`(git 제외)에만.
- 영상·음원·프로젝트 파일은 커밋하지 않습니다(`.gitignore` 가 막음). 경로만 적습니다.
- 커밋·푸시는 시킬 때만. 납품 파일은 같은 이름에 덮어쓰고, 폴더를 지우거나 이름을 바꾸지 않습니다.
- 새 텍스트 파일은 UTF-8(BOM 없음) + LF, `.ps1` 만 BOM.

**이 저장소에 없는 것** (각자 준비)
- 효과음 음원 라이브러리 — 등급표(`tools/data/예능효과음-등급.json`)와 고르는 법(`sfx-workflow.md`)만 있음
- 글꼴 파일, 로고, 영상 원본, 납품물
- 무음편집 도구가 쓰는 `subpipe` 패키지(`tools/config.py` 의 `SUBPIPE` 경로)
- 실명 목록(`기록/비공개/`, git 제외)
