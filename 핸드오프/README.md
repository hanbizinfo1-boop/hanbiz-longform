# 핸드오프 — 기획(이 컴퓨터) ↔ 제작(새 컴퓨터) 분업

> 사장님 10-13 원문: «지금 [이식받은 스킬파일 기반 워크플로우] 여기 세션 확인 대화로그 하고 앞으로는 너가 기획하면 저쪽에서 받아서 영상만드는 작업플로우를 만들어줘 충돌 병목없게끔 잘 조율하고 저쪽 컴퓨터에서 내가 확인하고 작업해라는 간단한말로 작업이 시작될 수 있는 작업플로우를 구성해줘»
> 배경: 10-13 쇼츠광고 세션에서 «컴퓨터 CPU가 너무 모자라서 다른컴퓨터에 자동화를 그대로 이식» — 새 컴퓨터(GPU 설치)에 롱폼 저장소 `hanbizinfo1-boop/hanbiz-longform` 을 그대로 받음.

## 1. 역할

| | 기획 컴퓨터 (`역할.json` 의 이름 — 지금 DESKTOP-GRL3850) | 제작 컴퓨터 (그 밖의 컴퓨터 — 새 PC) |
|---|---|---|
| 하는 일 | 사장님 지시 받기 · 연출 기획(연출표) · **길라잡이 관리**(규칙·충돌 정리·피드백 영구 기록) | 무거운 계산 전부(받아쓰기·OCR·강제 정렬·층 재구성·모자이크·렌더) · 검수 2번 · 납품 |
| 쓰는 파일 | `CLAUDE.md` `.claude/` `templates/` `tones/` `피드백/` `기록/` · 건 폴더의 `00_지시서.md` `20_연출표.*` | `tools/` `소재/` · 건 폴더의 `10_분석/` `30_결과.md` · `핸드오프/제작로그.md` |
| 남의 파일을 고치고 싶으면 | `00_지시서.md` «제작에 요청» 칸 | `30_결과.md` «길라잡이 반영 요청» 칸 |

**같은 파일을 두 컴퓨터가 쓰지 않는다** → git 충돌이 날 수 없다. `tools/handoff.py 올리기` 가 내 역할 파일이 아닌 것이 섞이면 올리기를 거부한다.

## 2. 사장님이 하시는 말 (이것만)

| 어디서 | 말 | Claude 가 하는 일 |
|---|---|---|
| 기획 컴퓨터 | «기획해 — 원문: ○○ / 느낌: ○○» (또는 지시 그대로) | 받기 → 새 건 → `00_지시서.md`(사장님 원문 그대로) → 분석이 필요하면 «분석부터», 아니면 연출표까지 → 올리기 |
| **제작 컴퓨터** | **«확인하고 작업해»** | 받기 → `handoff.py 상태` → 내 차례인 건을 순서대로: 분석 대기면 분석 → `10_분석/` 올리기 · 제작 대기면 연출표대로 만들기 → 검수 2번 → 납품 폴더 열기 → `30_결과.md` 올리기 |

| 어느 쪽이든 | 영상 보시고 피드백 | 그 컴퓨터의 Claude 가 원문 그대로 기록(제작이면 `30_결과.md` «받은 피드백») → 기획이 `피드백/`·길라잡이에 옮김 |

이 말들은 **그 범위의 받기·커밋·푸시까지 시킨 것**으로 본다(CLAUDE.md 6번 예외 — 사장님 10-13 «간단한말로 작업이 시작될 수 있는»). 그 밖의 커밋은 지금처럼 사장님이 시킬 때만.

## 3. 건 폴더 `핸드오프/<YYYY-MM-DD>_<건>/`

| 파일 | 쓰는 쪽 | 내용 |
|---|---|---|
| `00_지시서.md` | 기획 | 원문 경로(**제작 컴퓨터 기준**) · 모드(A/B) · 느낌 · 사장님 지시 원문 · 단계(«분석부터» / «바로 제작») · 지켜야 할 규칙 · 제작에 요청 |
| `10_분석/` | 제작 | `자막.txt`(줄·시각·글) · `받아쓰기.txt` · `자막검수.md`(맞춤법·타이밍 후보) · `화면색인.md`(구간별 화면·OCR 요약, 실명은 ○○) · `모자이크후보.md`(시각·칸·이유, 실명 없이) · `화면모음/*.jpg`(10초 간격 모음, 640px) · `층.md`(트랙·PIP·전체 화면 컷) |
| `20_연출표.md` (+`.py`) | 기획 | 장면마다: 자막 글로 시각(«"텔레그램에서 먼저" 줄 시작»), 화면 글자로 위치(«"고른 사람" 칸»), 연출 종류·템플릿·효과음 역할·근거(PB/fusion) · 연출 판 번호 |
| `30_결과.md` | 제작 | `상태: 완료` · 납품 경로 · 연출표 판 · 넣을 때 검수 · 전체 검수(원문 대조·OCR 개인정보·음량·자막) · 바꾼 곳(연출표와 다르게 한 것과 이유) · 받은 피드백 원문 · 길라잡이 반영 요청 |

단계는 파일이 있는지로 정해진다(따로 상태표를 두지 않는다 — 두 컴퓨터가 같은 표를 고치면 충돌): 지시서만 → (분석부터면) 분석 대기 → 분석 완료 → 연출표 → 제작 대기 → 결과 «상태: 완료».

## 4. 병목 없게

- **기다리지 않는다**: 제작은 연출표가 없는 건을 붙잡지 않는다(분석만 하고 다음 건). 기획은 결과를 기다리지 않고 다음 건을 기획한다.
- **분석은 한 번**: 받아쓰기·OCR 은 제작 컴퓨터가 한 번만 하고 `10_분석/` 에 남긴다. 기획 컴퓨터는 무거운 계산을 하지 않는다(CPU 부족이 분업 이유).
- **좌표는 글자로**: 연출표는 픽셀이 아니라 «화면 글자»로 위치를 말한다(10-13 실측: 축소 모음에서 잰 좌표는 ±30px 틀림). 제작이 OCR 로 찾는다.
- **연출표가 화면과 안 맞으면** 제작이 그 장면만 빼거나 고치고 `30_결과.md` «바꾼 곳»에 적는다(밤샘 중 승인 요청 금지 — 절대금지).
- **큰 파일**: 원문 mp4·prproj·원본 소스는 사장님이 컴퓨터마다 드라이브에서 따로 받는다 — git 으로는 도구·문서만 공유(10-13 «원본파일은 각각 드라이브에서 따로 받을거고 도구만공유되면 괜찮을듯해»). 지시서의 경로는 제작 컴퓨터 기준으로 적고, 없으면 제작이 `30_결과.md` 에 «원문 없음»으로 적고 다음 건으로. 렌더·납품은 제작 컴퓨터 `납품/` 에만.
- **시작 시점**: 롱폼 분업은 **다음 롱폼부터**(10-13 «롱폼은 다음 롱폼부터 작업진행할거야»). 파트너센터 본편은 이 컴퓨터에서 마무리.

## 5. 연출 엔진 — 애프터이펙트 없이 (10-13)

> 사장님 원문: «다만 에펙은 저기서 사용못해 이건알아둬» · «에펙말고 다른방향으로 연출해야해»

- 제작 컴퓨터에는 **애프터이펙트가 없다** → 연출표는 **AE 엔진 템플릿(`engine: ae`, 63개)을 고르지 않는다.**
- 쓰는 엔진: `compose`(파이썬 합성 — 실화면 확대·붓 획·칩·이미지 카드·흐림, 파트너센터 본편이 전부 이것) · `html`(HTML/CSS 장면 → 크롬으로 프레임 렌더) · `design`(클로드 디자인 → 이미지) · `pil` · Codex 이미지(구독 내 무료) · `aivideo`(유료 — 아침 승인제 그대로). `blender` 는 제작 컴퓨터 설치 확인 전까지 쓰지 않는다.
- **성제관(모드 C, 10-14)**: 촬영본 없이 녹음만 → 화면 메인은 **실제 자료 + 클로드 디자인**, 그 위 **연출·전환 = 리모션 · 블렌더 · Codex 이미지**(사장님 «실제자료 + 클로드디자인 이거 두개가 메인으로 여기에 연출 및 전환효과를 주는게 핵심이야»). 엔진 `remotion`(새로 추가) · `blender`(성제관에 쓰기로 함 — **제작 컴퓨터 첫 성제관 작업에서 Node/Remotion·Blender 설치부터 확인**하고 `30_결과.md` 에 버전을 적는다; 없으면 설치 요청을 «길라잡이 반영 요청»에). 리모션 타이포 연출 노트는 쇼츠광고 저장소 `typography-remotion.md` 참고.
- **대본이 있는 건(모드 C)**: 기획은 `20_대본.md` + `20_대본_검사.txt`(«결과: 통과») 를 같이 올린다. 제작은 검사 기록이 «통과» 가 아니면 시작하지 않는다(CLAUDE.md 15번).
- AE 템플릿이 «느낌상 꼭 맞는» 자리는 같은 연출을 `html`/`compose` 로 다시 만든다(옮긴 것은 템플릿에 새 번호로 등록). 기획 컴퓨터에서 AE 로 대신 렌더해 넘기지 않는다(«다른 방향으로»).

## 6. 두 컴퓨터가 같이 지키는 것

- 작업 시작 = `python tools/handoff.py 상태`(받기 포함) → `피드백/절대금지.md` · `원하는영상.md` · 그 건 폴더 전부 정독(CLAUDE.md 최상위 규칙).
- 개인정보: 분석·결과 문서에 실명을 쓰지 않는다(○○). 실명 목록은 각 컴퓨터 `기록/비공개/`(git 제외) — 기획이 정한 금지어 목록은 사장님이 직접 옮기거나 제작이 원문에서 다시 만든다.
- 첫 건(파트너센터 본편, 10-13)은 이 분업 전에 기획 컴퓨터에서 끝까지 만들었다 — `피드백/작업/2026-10-13_파트너센터_자동.md` 가 이후 건의 본보기.
