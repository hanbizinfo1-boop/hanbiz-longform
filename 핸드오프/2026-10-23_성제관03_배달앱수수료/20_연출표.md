## 1. 두 층 규격

**실물 층**
- 무엇: 실제 자리 — 저녁 가게(포장대·주방·홀·계산대) · 손님 쪽(집·거리) · 배달앱 화면을 다시 그린 것 · 조사 보고서 표를 다시 그린 것.
- 바탕: **따뜻한 저녁 실사**(텅스텐 3000K 안팎, 짙은 나무·스테인리스) — 1편 짙은 남색·검정 무대, 2편 흐린 오후·콘크리트와 다르게.
- 글: 실사 위 글은 어두운 판(`#1B1E22` 알파 255, 반경 12) 하나에 숫자만.
- 매체: Codex 사진(2.5D 포함) · 재현 화면(html) · 원문 카드(다시 그린 보고서 표).

**설명 층**
- 무엇: 모눈 도면 위 선 그림 — 흐름도 · 계단 막대 · 단면도 · 저울 · 시계 고리 · 큰 숫자 · 진행표 카드.
- 바탕: `#F4F5F2` + 모눈선 `#E3E6E8`(40px 칸, 5칸마다 조금 진하게 `#D5D9DC`) — 빈 단색판 금지(절대금지 10-12)라 모눈선이 반드시 보이게.
- 선·글: 선 `#20262D` 2.5px · 손그림 아닌 깔끔한 선 · 카드 테두리 1px `#C9CED3` · 그림자 거의 없음.
- 매체: html 선 그림 · html 차트 · html 큰 숫자 · html 표 · html 진행표 카드.

**색 — 주제 색 하나 + 두 뜻 색만**(모냐구 실측 «편마다 주제 색 하나»)
- 주제 색 **파랑 `#1F5FD1`** = 큰 숫자 · 수익 내는 쪽 · 지금 짚는 것. 1편(남색 바탕·여러 색)·2편(주홍·청록)과 겹치지 않는다.
- 빨강 `#D63A3A` = 손해·빠져나가는 돈·하면 안 되는 것. 초록 `#1E9E5A` = 확인(체크) — 한 편에 몇 번만.
- 그 밖의 색은 실사 사진 속 색뿐. 칸·카드는 바탕과 명도 차가 확실하게(10-19 칩 대비 규칙).

**진행표 카드 «가격 · 광고 · 단골»**(모냐구 위성 편 «4가지» 카드 — 한 편을 꿰는 장치)
- 가로 세 칸 카드(각 칸 = 선 아이콘 + 단어 하나). 처음엔 빈 칸 → 장이 시작될 때마다 다시 나와 **그 칸이 파랑으로 켜지고** 그 칸으로 들어가며 장이 시작 → 끝 정리에서 **세 칸 다 켜진 같은 카드 + 칸마다 앞 그림 다시 나란히**.
- 나오는 곳: 장면 7(처음 소개) · 9(가격) · 37(광고) · 54(단골 — 앞 두 칸을 받치는 모양) · 68(정리).
- **화면 구석 이름표 칩은 쓰지 않는다** — 모냐구는 왼쪽 위에 장 이름 칩을 상시로 두지만, 절대금지 [10-12 쇼츠] «화면 위 구석 진행 표시·잔글씨» · 2편 10-20 «구석 이름표 칩으로 때우기 금지»와 부딪힌다 → 장 표시는 이 진행표 카드가 맡는다.

**근거 숫자 = 원문 카드 + 형광펜 + 출처 줄**
- 원문 카드(«실제 문서 문장» 카드)는 사장님 확인 대기(monyagu 5-4) → 이번 편은 **문장을 옮기지 않고**, 보고서 표를 다시 그린 카드에 숫자만 + 형광펜(파랑 반투명, 글자 뒤) + **카드 바로 아래** 출처 줄(회색 `#7A828A`, 화면 높이 2% 안팎). 출처 줄은 화면 구석에 따로 띄우지 않고 카드·사진에 붙인다.
- 출처 문구: 서울시 숫자 = «출처: 서울특별시 배달플랫폼 상생지수 (2025.12)» · 중기부 = «출처: 중소벤처기업부 2025 배달앱 입점업체 조사» · 방송 정산 = «방송 보도 찌개집 정산 사례 · 다시 그림». 보고서 표지·로고를 베끼지 않는다(제목 글과 숫자만).

**재현 화면 · 사진 속 글**
- 실제 앱 이름·상표·로고 없음, 가게 이름 ○○, 전화 010-0000-0000. 화면 속 글은 `20_대본.md`·녹음 원고에 나온 말·숫자만 — 지어낸 금액·통계 숫자 넣지 않는다(숫자가 필요 없으면 막대·눈금으로).
- 계산 장면 숫자(대본의 «대충 계산» 가정): 떡볶이 8,000원 → 중개 7.8% 624 + 결제 3% 240 + 배달비 3,000 = **3,864 ≈ «4천 원 가까이»** · 세 그릇 24,000원 → 1,872 + 720 + 3,000 = **5,592 ≈ «6천 원 조금 안 됨»**. 화면엔 대본 표현(«≈ 4,000원» «6,000원 미만» «½ → ¼»)으로.

**속도 · 소리** — 2편 `20_연출설계.md` 2장 수치 그대로(화면 2초 넘게 같은 상태 없음 · 전체 화면 바뀜 2.5초 이상 · 등장 0.10~0.12초 감속 · 키프레임 2번 · 효과음 2초에 1개 안팎 · −14 LUFS · 트루피크 −1.5 · BGM −19dB). 전환은 모냐구처럼 **거의 컷**(짧은 디졸브는 층이 바뀔 때만 몇 번).
