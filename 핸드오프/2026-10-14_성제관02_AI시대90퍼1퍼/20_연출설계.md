# 성제관02 연출 설계 — 1편 퀄리티·속도감 그대로, 분위기·색감·도구·구도는 다르게

> 작업하는 동안 **이 문서를 계속 펴 두고** 장면마다 다시 본다. 연출표(`20_연출표.md`)나 SPEC 과 부딪히면 이 문서가 우선이다.

## 0. 사장님 원문 (10-16)
- «기존 영상에서 쓴 연출방법 연출구조 느낌은 비슷하게가되 분위기는 달라야해 / 색감 쓰는 연출도구 연출구도 다르게가야해»
- «나는 그 속도감 연출하는 방식 방법이 마음에들었고 1편에 분위기 도구 구도도 마음에 들었는데 중복느낌이 나지않았으면 좋겠다는거야 이거 작업하면서 계속 참고할수있게끔 설게해서 지시해줘»
- «즉, 1편이 정말 마음에 들었으니 1편 정도의 퀄리티를 유지하면서 즉, 속도감이나 퀄리티는 마음에 들었다 근데 2편이 1편과 너무 유사한 분위기 구도 장면 연출 이게 동일하면 안된다는 얘기를 하는거야»
- «하다가 규칙누락되거나 애매한 상황나오면 1편 참고해서 내가 말한 비슷하지 않게 이 두가지만 충족해서 연출해달라고도 말해주고»
- «BGM 부족해서 어울리지 않는 느낌이면 더 다운받는것도 허용한다고 해줘»

## 1. 애매하거나 규칙이 비어 있을 때 — 이 두 가지만 맞추면 된다
규칙이 없거나, 규칙끼리 부딪히거나, 어떻게 할지 애매하면 **1편(`tools/scenes/sjk01/` · 1편 완성본)을 열어 보고** 아래 두 가지를 모두 맞추는 쪽으로 정해서 진행한다. 묻지 않는다(밤샘 — 승인 요청 금지). 정한 것은 `30_결과.md` «애매해서 정한 것»에 한 줄씩 적는다.

| | 기준 | 확인 방법 |
|---|---|---|
| ① | **1편만큼 빠르고, 1편만큼 잘 만들었다** — 속도감·연출 수량·효과음 밀도·화면 완성도가 1편 v6 아래로 내려가지 않는다 | 2장 수치 그대로 지킴 · 1편 같은 길이 구간과 1초 간격 프레임 띠를 나란히 놓고 봄 |
| ② | **1편과 비슷해 보이지 않는다** — 같은 분위기·같은 색감·같은 연출 도구·같은 구도·같은 장면이 없다 | 3장 표 · `scene_check.py --prev` ERROR 0 · 1편과 2편 프레임 띠를 나란히 놓았을 때 «같은 영상의 다음 장면 같다» 싶으면 고친다 |

## 2. 그대로 가져가는 것 — 1편 «연출 방법·구조·속도감·퀄리티»
1편 `tools/scenes/sjk01/SPEC.md` 0장 + `SPEC_V2.md` 1~11장의 **수치와 방법**은 2편에도 그대로 쓴다. 바뀌는 건 3장의 «겉모습»뿐이다.

| 항목 | 2편에도 그대로 (1편 실측) |
|---|---|
| 장 구조 | 장마다 다른 세계 · 공들인 한 방 2개 · 처음과 끝이 같은 곳(수미상관) |
| 속도 | 화면 2초 넘게 같은 상태 없음(얹는 요소로 채움) · 전체 화면 바뀜 사이 2.5초 이상 · 장면 전환 0.3~0.4초 · 등장 0.10~0.12초 감속 · 목록은 항목마다 한 박자 |
| 첫 5초 | 말 한 줄(1~2초)마다 다른 숏으로 끊고 숏마다 변화 하나 — 한 그림 천천히 확대 금지 |
| 키프레임 | 한 그림·한 요소 강조 2번까지 · 왔다 갔다 금지 · 순간 확대 컷 금지 |
| 부각 | 시간·금액·퍼센트·개수·핵심어 — 장면당 2번까지(겉모습은 3장에서 바꿈) |
| 연출 수량 | 짚는 표시(형광펜은 글자 뒤·동그라미·밑줄·화살표·확대 창·개념어 칩)·카운트·화면 안 내용 바뀜 — 1편과 비슷한 수 |
| 재현 화면 | 실제 플랫폼 화면 모양(리뷰·소식·메뉴·대화창·스프레드시트) · 빈 대화창으로 시작 안 함 · 상표·실제 앱 이름 없음 |
| 동작 | «시킨다»«답글 단다»는 타자 → 보내기 → 결과까지 그 동작이 보이게 |
| 장면 정합성 | 말이 가리키는 물건·장소 속에서 보여 줌 |
| 효과음 | 2초에 1개 안팎 · 같은 역할 연달아 금지 · 들리는 중 잘림 0 · 크기는 sfx.md 3장 |
| 소리 | −14 LUFS · 트루피크 −1.5 · BGM 목소리 말 중앙 **−19dB**(10-16 현행, 평탄, 덕킹 없음) |
| 자막 | 글꼴·자리·크기는 1편과 같게(채널 통일) · 줄 끝 마침표 없음 |
| 검수 | 13번 두 번 · 장면마다 정지 화면 눈 확인 · `scdet` 2.5초 안 연속 바뀜 0 |

## 3. 바꾸는 것 — 분위기 · 색감 · 연출 도구 · 구도 · 장면
**1편에서 쓴 것은 2편에서 쓰지 않는다**(왼쪽 칸). 오른쪽 칸이 2편 기본값이다.

### 3-1. 분위기
| 1편 | 2편 |
|---|---|
| 밤 11시 · 따뜻한 가게 불빛 · 야근하는 대표님을 위로하는 밤 | **흐린 낮 → 새벽** · 차가운 회색빛에서 시작해 마지막에 새벽 첫 불이 켜짐 · «다 똑같아진 거리에서 하나만 다르게 남는» 긴장감 |
| 장 세계: 밤 거리 → 휴대폰 속 → 주방·뒷방 → 숫자의 방(남색) → 빈 무대 → 밤 거리 | 장 세계: 흐린 오후 상가 거리 → 똑같은 것들이 줄 선 벽 → 바랜 옛날 사진(배달앱 처음) → 상담 탁자 → 새벽 주방(글) → 감열지 영수증 위(숫자) → 점심 지난 홀(시간) → 새벽 거리(끝) |

### 3-2. 색감
| 1편 | 2편 |
|---|---|
| 종이 #ECE8E0 · 먹 #15181C · 코발트 #2E55D9(AI) · 노랑 #F2C230(핵심) · 빨강 #D8402F(지움) | 바탕 콘크리트 #D9DBD6 · 글 짙은 청회색 #1F2A33 · **주홍 #F05A28 = 우리 가게만 있는 것(1%)** · 청록 #1FA39A = AI 가 하는 것 · 탈색 회색 #9AA0A6 = 다 똑같은 것(90%) |
| 형광펜 노랑 · 부각 글 종이색 | 형광펜 주홍 옅게(글자 뒤 아래 절반) · 지우기는 빨강 ✕ 대신 **색이 빠져 회색이 됨** |
| 사진 톤: 따뜻한 밤, 텅스텐 빛 | 사진 톤: 흐린 낮·새벽 푸른빛, 낮은 채도, 필름 결 — 주홍 하나만 살아남게 |

**2편의 색 규칙 하나**: «다 똑같은 것»은 회색으로 빠지고 «우리 가게만 있는 것»만 주홍으로 남는다. 영상 전체가 이 규칙 하나로 읽히게 한다(제목 90% / 1%).

### 3-3. 연출 도구 (엔진 `html_motion`·조립기·소리 도구는 같이 써도 된다 — 바꾸는 건 화면에 보이는 도구)
| 1편 | 2편 |
|---|---|
| 손에 든 휴대폰·노트북·태블릿 사진의 초록 화면에 UI 원근 얹기(장면 다수) | **기기 사진은 4장면 이하.** UI 는 화면 크게 띄운 판을 6~12° 기울이고(원근 기울기) 콘크리트·감열지·탁자 위에 얕은 그림자 · AI 대화창은 **다크 테마**(1편 밝은 대화창과 다른 배치) |
| 깊이 지도 2.5D 카메라 밀고 들어가기(오프닝·복도·무대·거리) | 2.5D 는 **옆으로 흐르는 트래킹**만(밀고 들어가기 금지) · 미니어처(틸트시프트) 하이앵글 사진 |
| 블렌더 3D 막대 · 히트맵 · 숫자의 방 | 숫자는 **폭포 차트**(매출에서 항목이 하나씩 빠져 내려가 수익이 남음)를 감열지 영수증 띠 위에 |
| 부각: 가운데 큰 명조(Serif 900) + 배경 흐림·어둡게 | 부각: **배경이 탈색(흑백)** + 큰 굵은 고딕을 왼쪽 아래 3분의 1 자리에, 주홍 밑판 · 가운데 정렬 금지 |
| 글꼴: Noto Serif KR(큰 글) · IBM Plex Sans KR/Mono(판·라벨) · Nanum Pen Script(손글씨) | 큰 글 = 굵은 고딕(Pretendard Black 등 OFL) · 라벨 = 고딕 작은 글 자간 넓게(Mono 금지) · 손글씨 = 다른 손글씨체(Gaegu 등 OFL). 받은 글꼴은 `소재/fonts/` + 라이선스 기록. 자막 글꼴만 1편과 같게 |
| 전환: 휙(옆·위)·확대·축소·밀기·갈라짐·지우개·디졸브 돌림 | 전환(0.3~0.4초 그대로): **셔터 내림/올림 · 탈색 넘김(색이 빠지며 다음 장면) · 모양 이어 붙이기(솥 뚜껑 원 → 다음 장면의 원) · 옆 흐름 이어짐(카메라가 옆 칸으로) · 카드 뒤집기 · 모양 안으로(글자·창 안으로 들어감) · 컷**. 1편 전환 종류는 전체의 20% 이하, 같은 전환 연달아 금지 |
| 장 제목 카드: Mono 번호 «01» + 명조 제목 | 장 번호는 세계 안의 물건에 새김(셔터 스텐실 «1»·영수증 인쇄 «2»·홀 테이블 번호 «3») |
| 효과음 단골: 전환마다 휙/스윕 | 뜻이 맞으면 셔터·종이 찢김·감열지 출력·불 켜짐 소리로(예능 라이브러리 읽기만) · 휙은 1편보다 적게 · 밀도는 2장 그대로 |

### 3-4. 구도
| 1편에 많던 것 | 2편 기본 |
|---|---|
| 와이드 밀고 들어가기 · 정면판 · 탑뷰 · 손에 든 기기 속 화면 · 반반 분할 비교 | **옆 트래킹 · 로우앵글 · 정면 대칭 격자(똑같은 것들이 나란히) · 매크로 극접사(김·칼·배추·감열지 글자) · 어깨 너머(얼굴 안 보임) · 앞 흐림/뒤 선명 초점 옮기기** |
| A/B 비교 = 화면 반반 | A/B 비교 = **같은 자리에서 A 가 회색으로 빠지고 B 만 색이 남음**, 또는 앞뒤 초점 옮기기(반반 분할 금지) |

### 3-5. 장면 — 1편과 같은 그림 금지
- 밤 거리 · 불 켜진 한 집 · 유리문 통과 · 3D 복도의 문 셋 · 빈 무대 스크린 · 숫자의 방 · 시계 숫자 부각 · 모래시계 · 칠판 · 게시판 공고 벽 · 계약서·도장 · 3D 막대 · 단골 실루엣 사라짐 — **2편에서 쓰지 않는다.**
- 같은 말이 나와도 그림은 새로: «리뷰 답글»(1편: 밤 손에 든 휴대폰) → 2편은 다크 테마 대화창 + 리뷰 카드가 격자에서 하나만 주홍으로 · «알바 공고»(1편: 게시판 벽) → 2편은 구인 앱 목록 격자, 전부 같은 글.
- 1편 Codex 사진(`소재/sjk01/codex/`)은 다시 쓰지 않는다. 2편 사진은 `소재/sjk02/codex/` 에 새로.

## 4. 공들인 한 방 2개
- **★1 «90% / 1%»** ([04] 약속 «사라지는 90% 쪽인지 살아남는 1% 쪽인지») — 미니어처 상가 하이앵글. 셔터 가게 100칸이 줄줄이 회색으로 빠지며 셔터가 내려가고 **한 칸만 주홍 불이 남는다**. 숫자 «90%» «1%»는 탈색 부각으로.
- **★2 «그 한 줄이 따라다닌다»** ([05] 끝 «그게 한 달 쌓이면 … 그 새벽 5시 국밥집») — 주홍 한 줄 «새벽 5시에 불 올려서»가 메뉴 설명 → 리뷰 답글 → 소식 글 화면으로 옆 흐름으로 건너가고, 마지막에 **손님 리뷰 안에 같은 말이 손님 글씨로** 나타난다. 가게 이름보다 그 줄이 먼저 남는 그림.

## 5. 처음과 끝 (수미상관 — 1편과 반대 방향)
- **처음**(첫 5초 숏 끊기): ① 셔터 슬랫 매크로 — 셔터가 탁 내려옴 ② 로우앵글 불 꺼진 간판 ③ 옆 트래킹, 셔터 가게가 줄줄이(탈색) ④ «AI 덕분에»에 휴대폰 알림이 쌓이는 손(어깨 너머). 1편처럼 밤 거리로 밀고 들어가지 않는다.
- **끝**([08] «오늘 밤에 가게 문 닫으시고» → «내일») : 새벽 5시 거리, 줄줄이 내려간 셔터 사이 **한 가게 셔터가 올라가고 주방 화구에 불이 켜진다**(처음 «셔터 내림»의 반대). 끝 화면은 1편과 같은 채널 끝 화면 틀 위에 2편 색으로.
