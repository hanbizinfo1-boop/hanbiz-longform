# 숏폼세션구축 — 작업 목록 (이 건은 영상이 아니라 설정이라 연출표 자리에 작업 목록)

먼저 정독: `00_지시서.md` → `핸드오프/README.md` 7장 → `.claude/skills/shorts/SKILL.md` → `CLAUDE.md` «숏폼 전용 세션» 절.

## 1. `tools/handoff.py` (롱폼 저장소에서 고치고 테스트)

1. `role()`: `핸드오프/역할.local.json` 이 있고 `"역할"` 이 «숏폼»이면 `("숏폼", 컴퓨터이름)` 을 먼저 돌려준다. 없으면 지금처럼 기획/제작.
2. `OWN["숏폼"] = ["핸드오프/*/40_", "tools_shorts/", "핸드오프/숏폼로그.md"]`. 제작·기획 목록은 그대로(`tools_shorts/` 는 `tools/` 와 접두가 달라 겹치지 않음 — 확인).
3. 숏폼 단계 함수 `stage_shorts(job)`:
   - `20_쇼츠기획.md` 없음 → 표시 안 함(쇼츠 없는 건)
   - `40_쇼츠결과.md` 에 «상태: 완료» + «받은 피드백»이 «(없음)» 아님 → «쇼츠 완료 · 피드백 → 기획» (다음: 기획)
   - `40_쇼츠결과.md` «상태: 완료» → «쇼츠 완료 — 사장님 확인 대기»
   - 롱폼 `30_결과.md` «상태: 완료» 아님 → «쇼츠 — 롱폼 대기» (다음: 제작)
   - 그 밖 → **«숏폼 대기» (다음: 숏폼)**
4. `cmd_status`: 건마다 롱폼 단계 한 줄 + (쇼츠기획이 있으면) 쇼츠 단계 한 줄. «← 내 차례» 표시는 역할 기준.
5. 롱폼 제작 세션은 쇼츠를 만들지 않는다 — 롱폼 `30_결과.md` «상태: 완료»는 쇼츠 없이 낼 수 있다. (1편은 이미 밤샘 지시에 쇼츠가 들어 있어서 나온 것이 있으면 그대로 두고 `30_결과.md` 에 «쇼츠: 만듦/안 만듦»만 적는다 — 숏폼 세션이 이어받는다.)
6. `cmd_new` 은 기획만(그대로). `cmd_push` 는 역할별 `OWN` 으로 거부(그대로 — 숏폼 목록만 추가).
7. 테스트: 롱폼 폴더에서 `python tools/handoff.py 역할` → «제작». 임시로 `역할.local.json` 을 만들어 «숏폼» 이 나오는지 보고 **바로 지운다**(롱폼 폴더엔 남기지 않는다).

## 2. `tools/resume_guide.py`

- 역할이 «숏폼»이면 롱폼 상시 규칙·점검표 대신: `.claude/skills/shorts/SKILL.md` 1~4장 머리줄 · `피드백/절대금지.md` 전부 · `handoff.py 상태` 의 숏폼 줄 · «숏폼 세션 — 롱폼 규격·모드 표는 쓰지 않는다» 한 줄.

## 3. 숏폼 폴더 만들기

1. 위 1·2 를 `python tools/handoff.py 올리기 "숏폼 세션 — 역할·단계·안내"` 로 먼저 올린다.
2. `git clone <이 저장소 원격 주소> "D:\숏폼전용"` (원격 주소는 `git remote get-url origin`).
3. `D:\숏폼전용\핸드오프\역할.local.json` (UTF-8, BOM 없음):
   `{"역할": "숏폼", "롱폼경로": "<이 롱폼 저장소 절대경로>"}`
4. 확인: `D:\숏폼전용` 에서 `python tools/handoff.py 상태` → 첫 줄 «역할 «숏폼»» · 성제관01 에 쇼츠 단계 줄이 나오는지. `git status` 에 `역할.local.json` 이 안 보이는지(.gitignore).
5. `D:\숏폼전용\납품\` 이 있는지(없으면 만든다 — git 제외 폴더).
6. Claude Code 프로젝트 설정(`.claude/settings.json`)은 저장소에 있어 같이 따라온다 — 따로 만들지 않는다.

> 제작 PC 에서 새 터미널 → `cd "D:\숏폼전용"` → `claude` → «숏폼 확인하고 작업해»
