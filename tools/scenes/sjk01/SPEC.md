## 0. 모든 장면 공통 규칙 (사장님 영구 금지·상시 규칙 — 하나라도 어기면 반려)

1. **반복 금지** — 이 영상의 핵심 지적. 장면마다 바탕·매체·구도·카메라가 앞 장면과 달라야 한다. 아래 표의 «바탕»을 지키고 임의로 같은 판으로 바꾸지 않는다.
2. **단색 배경 금지** — 바탕은 `.tex-paper/.tex-ink/.tex-navy/.tex-chalk/.tex-map/.tex-desk` 질감 또는 사진(`소재/sjk01/codex/*.png`). 그라데이션만 깐 판 금지.
3. **도형으로 사물 흉내 금지** — 휴대폰·노트북·태블릿·모래시계·책·도장 같은 **물건을 CSS 도형으로 그리지 않는다**. 물건은 사진(Codex)으로. 기기 화면 속 UI 는 사진의 초록 화면 네 모서리(`소재/sjk01/codex/quads.json`)에 `S.fitQuad(el, w, h, quad)` 로 원근을 맞춰 얹는다. 앱·AI 대화창·엑셀·문서 같은 **화면/종이 자체**는 HTML 로 그린다(그게 «재현 화면»). 종이는 `.print` 질감 + 그림자.
4. **화면에 «재현»«AI 재현 영상»«연출» 같은 고지·라벨 금지.** 실제 상호·전화(010-0000-0000 만)·계정 X. 가게 이름은 쓰지 않거나 «○○국밥».
5. **화면 글은 말을 따라 쓰지 않는다** — 재현 화면 안의 글(앱·AI 답·문서)은 `20_재현자료.md` 그대로, 그 밖의 글은 개념어·숫자 몇 단어(Serif 900 큰 글 / Mono 라벨). **«» 따옴표 대사 금지**. 자막이 따로 들어가므로 말을 옮겨 적은 해설 글을 옆에 띄우지 않는다.
6. **움직임** — 등장은 `S.ent()`(EO 감속, 0.12~0.16초, 튕김·오버슈트 0). 카메라·판 이동은 `S.cam()`(EZ). **흔들기·떨림·깜빡이는 그레인·바운스·폭죽·이모티콘·까만 화면 전환 금지.** 정지 화면으로 3초 넘게 멈추지 않는다 — 3~6초마다 그 말에 맞는 변화(새 요소·강조·카메라 밀기)가 있어야 하지만, 말에 없는 요소를 끼워 넣지 않는다.
7. **모든 움직임은 그 말의 시각에** — `S.at('낱말')` 로 잡는다(숫자는 `S.at('15분')` 처럼 화면 글자 그대로; 못 찾으면 콘솔 경고가 나오니 다른 낱말로). 새 요소는 혼자 0.6초 이상(같은 종류는 묶어서 같이).
8. **자막 자리 비우기** — y 965 아래(가운데 300~1620)에 중요한 글·요소를 두지 않는다(`BOXES` keepout 이미 있음). 화면 가장자리 15px 안쪽에 data-box 요소 금지(풀블리드 사진·판은 data-box 를 붙이지 않거나 `data-box-bleed`).
9. **색** — 종이 #ECE8E0 · 먹 #15181C · 코발트 #2E55D9 = AI 가 하는 것 · 노랑 #F2C230 = 사람이 봐야 하는 것·핵심 한 줄 · 빨강 #D8402F = 틀림·지움(필요한 장면만). `window.PALETTE` 에 장면 색을 적는다(재현 앱 UI 의 회색은 빼도 됨). 형광펜은 글자를 덮지 않게(글자 뒤 아래쪽 절반 `.mark`).
10. **글꼴** — 제목·큰 숫자 `.serif`(Noto Serif KR 900) · 판 글 Plex · 라벨 `.mono` · 앱/AI UI `.ui`(Noto Sans KR) · 손글씨 `.pen`. 글자 크기: 큰 숫자 120~220px, 판 글 30~44px, 재현 UI 본문 22~30px(1080p 에서 읽혀야 함).
11. **효과음 계기** — `S.ev(τ, 역할, id)` 를 장면 스크립트 맨 위(seek 밖)에서 적는다. 역할(그림이 실제로 바뀌는 프레임에만): `in`(판·장면 들어옴) `card_in`(카드·칸 쑥) `msg_in`(메시지·말풍선) `big_in`(큰 글 쿵) `ok`(맞음·체크) `no`(틀림·지움·✕) `type`(타자 시작) `marker`(밑줄·동그라미·형광펜 긋기) `stamp`(도장 그림일 때만) `page`(종이 넘김·출력물) `sweep`(자료 날아듦) `gauge`(막대·게이지 차오름) `shine`(핵심 반짝) `click`. 새 요소 등장은 이름 끝에 `_in` 을 붙인다(인지 텀 점검용). 한 장면 4~8개 정도, 같은 역할 바로 연달아 금지.
12. **장 제목 카드**(번호를 말로 부르는 줄: «첫 번째», «두 번째» …) — 큰 번호(Mono «01»~«10»)와 짧은 제목(Serif) 을 그 장면 세계 안에 1.5~2.5초 놓았다가 본 장면으로 넘어간다. 장마다 놓는 자리·모양을 다르게(같은 카드 복붙 X).

## 1. 만드는 법

1. `html/s04.html` 을 복사해 `html/sNN.html` — `<script src="../data/sNN.js">` 번호를 바꾼다. 장면 시각 τ: 0 = 첫 말 0.25초 전, `S.SC.dur` = 장면 길이. (앞 전환 여유 `pre` 동안 τ<0, 뒤 `post` 동안 τ>dur 이 되며 그때도 그림이 있어야 한다.)
2. `S.at()` 으로 시각 표 `T` 를 먼저 만들고, `S.scene(tau => {...})` 안에서 모든 스타일을 τ 의 함수로 계산(transition·animation·setTimeout·Math.random·Date.now 금지).
3. 렌더: `PYTHONIOENCODING=utf-8 py -3.11 tools/html_motion.py tools/scenes/sjk01/html/sNN.html --sub 1 --workers 4 --out _tmp/sjk01/render --name sNN`
4. 확인: `_tmp/sjk01/render/sNN_점검.txt` ERROR 0(WARN 은 이유를 보고). `sNN_sheet.jpg` 와 말 시각마다 `ffmpeg -ss <초> -i sNN.mp4 -frames:v 1` 로 뽑은 정지 화면을 **눈으로 본다**(Read 로 이미지 열기): 글자 잘림·넘침·겹침·안 읽히는 크기·빈 화면·자막 자리 침범·사진에 얹은 UI 원근 어긋남. 고치고 다시 렌더.
5. 사진 장면의 사진이 아직 없으면(Codex 생성 중) 그 장면은 맨 뒤로 미루고 다른 장면부터.

## 3. 사진 쓰는 법 (Codex 사진 — `소재/sjk01/codex/`, 1536×1024)

- 장면 HTML 에서 경로: `../../../../소재/sjk01/codex/<이름>.png`. 판에 깔 때 `.bg` + `background-image` (cover → 가로 1.25배, 위아래 100px 잘림). 카메라 밀기는 사진 래퍼 div 를 `transform: scale/translate`(EZ, 느리게, 정수 픽셀 반올림 금지 — 소수점 그대로). 확대는 최대 1.35배(사진이 뭉개지지 않게).
- 기기 사진(d09·d10·d14·d21·d29·d42)은 **`<이름>_clean.png`**(초록을 지운 사본)를 깔고, 화면 UI 는 `소재/sjk01/codex/quads.json` 의 `[이름][k].stage` 네 점에 `S.fitQuad(el, 너비, 높이, quad)` 로 얹는다(quads 는 cover 로 깐 판 좌표). 휴대폰 화면 UI 는 모서리 둥글게(border-radius 화면 너비의 7% 정도), quad 를 안쪽으로 1% 줄여 베젤 침범 방지. d21 은 휴대폰 3개(왼쪽부터 0·1·2), d42 는 태블릿 화면 + `d42_tablet_desk_paper` 흰 종이.
- quads.json 을 장면에서 읽으려면 fetch 대신 값을 장면 파일에 그대로 복사해 넣는다(파일 URL fetch 막힘).
