사장님 10-20: «검수한번해봐 전체적으로 문제있는곳 꽤나보인다 한번 자가검수 고고»
납품본을 2.5초 간격으로 전부 보고 찾은 문제. 장면 HTML = `tools/scenes/sjk02/html/sNN.html` (1920×1080).

## 공통 규칙 (모든 장면)
- 흔들기 금지 · 단색 배경판 금지 · 말 따라 쓰는 화면 글 금지 · «사장님» 화면 글 금지 · «» 따옴표 금지.
- 구석·가장자리 작은 이름표 금지: 글이 가장자리 160px(좌우)/140px(위아래) 안에 붙지 않게. 이름표·설명 글은 44px 이상.
- 판·카드·패널은 화면 밖으로 잘리지 않게: 위아래 여백 ≥ 90px, 좌우 ≥ 120px(카메라 밀기 중에도). 자막 자리(y 960~1080, 가운데)를 덮지 않는다.
- 빈 판 금지: 판·카드가 뜨면 0.3초 안에 첫 내용이 같이 보이게(빈 판이 1초 넘게 떠 있지 않게).
- 전체 화면 레이어에 `data-box` 를 붙이지 않는다(검사기 ERROR).
- 효과음 신호(S.xxx / cue)는 이름·뜻을 유지한다. 시각이 바뀌면 그 요소 등장 시각에 맞춰 같이 옮기고, 바꾼 것을 보고에 적는다.
- 고친 뒤: 렌더
  `PYTHONIOENCODING=utf-8 py -3.11 C:/Users/user/Desktop/한비즈-롱폼자동화/tools/html_motion.py C:/Users/user/Desktop/한비즈-롱폼자동화/tools/scenes/sjk02/html/sNN.html --sub 1 --workers 2 --out C:/Users/user/Desktop/한비즈-롱폼자동화/_tmp/sjk02/render --name sNN`
  → 규칙 점검 ERROR 0 확인 → `py -3.11 tools/scenes/sjk02/review_sheet.py sNN --n 8` → `_tmp/sjk02/review/sNN_rv.jpg` 를 Read 로 직접 보고 아래 «완료 기준» 확인.
  → `PYTHONIOENCODING=utf-8 py -3.11 tools/screen_text_audit.py tools/scenes/sjk02/html/sNN.html` ERROR 0.
- Bash 에서 `cd` 금지(절대 경로). 커밋 금지. 다른 장면·도구 파일 수정 금지.
