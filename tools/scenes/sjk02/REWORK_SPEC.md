## 0. 이번에 더한 공통 규칙 (어기면 반려)
1. **칩(`.chip`)·손글씨 메모로 말을 요약해 띄우지 않는다.** 화면에 얹는 글은 ① 숫자(금액·시간·개수) ② 3글자 이하 개념어 이름표 ③ 재현 화면(앱·대화창·종이·메뉴판·영수증·전단) 안 글뿐. 재현 화면 상자에는 `data-diegetic` 을 단다(`.app/.dk/.sheet/.thermal` 은 자동).
2. 재현 화면 안 글은 **읽히는 실제 예시 글**(회색 줄 막대·블러 자리표시 금지 — 절대금지 10-07). 글은 녹음 원고·이 명세에 있는 것만. 가게 이름 ○○국밥, 사람 이름은 «김**» 식.
3. 큰 글 + 스포트라이트(R7)는 **s28·s37·s53·s70 네 장면만**. 다른 장면에 큰 제목 글 금지.
4. 위 작은 글 + 큰 글 + 아래 설명 «세 단 쌓기» 금지(AI 말투 — 10-19).
5. `S.focus`(탈색 + 왼쪽 아래 큰 글)는 숫자 부각에만, 장면당 1번 이하. 이번 명세에 «부각»이라고 적힌 장면만.
6. 장면마다 `window.DEVICES = ['주 장치', …]` 를 적는다(아래 표의 «장치» 칸 그대로). 검사기 T5 가 연속 반복을 본다.
7. 새 사진은 `소재/sjk02/codex/n*.png`(글 없는 사진 — 글은 html 로 원근 맞춰 얹기: `S.fitQuad` 또는 CSS `perspective/rotate`). 콘크리트 바탕 `.tex-conc` 는 **s73 만** 남긴다.
