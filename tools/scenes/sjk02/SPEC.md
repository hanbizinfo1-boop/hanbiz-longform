## 0. 모든 장면 공통 (하나라도 어기면 반려)

**1편에서 그대로(속도·퀄리티)**
1. 화면이 **2초 넘게 같은 상태로 있지 않는다** — 새 요소·타자·형광펜/동그라미/밑줄 그리기·숫자 카운트·체크·화면 안 내용 바뀜·부각 중 하나가 2초 안에(말에 있는 것으로만).
2. **전체 화면 바뀜**(다른 사진·화면으로 넘어감, 화면 대부분이 바뀌는 카메라 이동)은 **서로 2.5초 이상** 떨어진다(장면 시작 포함). 순간 확대·이동 컷(d=0.001) 금지. 짧은 변화는 화면 일부에 얹는 것으로.
3. **키프레임 강조는 한 그림·한 요소에 2번까지**(밀고 들어가기 1 + 빠지기 1 등) · 왔다 갔다 금지. 느린 바탕 흐름(트래킹·1.00→1.04)은 세지 않음(방향을 바꿔 되돌아오면 셈).
4. 등장 `S.ent(t, a, 0.10~0.12)`(EO 감속, 튕김 0). 카메라·판 이동은 0.3~0.5초 `S.cam`. 목록은 항목마다 그 말 시각에 한 박자씩.
5. **흔들기·떨림·깜빡이는 그레인·바운스·폭죽·이모티콘·까만 화면·말풍선(흰 판+꼬리)·«» 따옴표 대사·«재현/연출» 라벨 금지.**
6. **도형으로 물건 흉내 금지** — 휴대폰·노트북·셔터·솥·프린터 같은 물건은 사진(Codex). 화면·종이·표·대화창·앱 UI 는 HTML(재현 화면). 셔터 «내려옴»도 사진 + 사진 가림(아래 3-3) 또는 사진 두 장으로.
7. **화면 글은 말을 따라 쓰지 않는다** — 재현 화면 안 글은 녹음 원고 그대로, 그 밖은 개념어·숫자 몇 단어.
8. 모든 움직임은 그 말의 시각(`S.at('낱말')`) — 못 찾으면 콘솔 경고 → 다른 낱말로. 새 요소는 혼자 0.6초(같은 종류 묶음은 0.25초 간격 허용).
9. 자막 자리 비우기: y 965 아래(가운데 300~1620)에 중요한 글·요소 금지(BOXES keepout 있음). 화면 가장자리 15px 안 data-box 금지(풀블리드는 data-box 없이).
10. 부각 `S.focus([...])` — 시간·금액·퍼센트·개수·핵심어, **장면당 2번까지**, 0.9~2.0초. 2편 모양(탈색 + 왼쪽 아래 굵은 고딕 + 주홍 밑판)은 lib 가 그린다.
11. 효과음 계기 `S.ev(τ, 역할, id)` — 그림이 실제로 바뀌는 프레임에만, **2초에 1개 안팎**, 같은 역할 바로 연달아 금지. 역할: `in`(판·장면 들어옴) `card_in`(카드·칩·칸) `msg_in`(메시지·알림) `ok`(맞음·체크) `no`(지움·회색으로 빠짐) `type`(타자 시작) `marker`(밑줄·동그라미·형광펜) `page`(종이·영수증 출력) `paper`(종이 넘김·찢김) `gauge`(막대·차트 차오름) `shine`(핵심 반짝) `click`(누름·불 켜짐) `shutter`(셔터 내림/올림 — 그림이 셔터일 때만) `sweep`(자료 날아듦). 부각은 자동.
12. 동작은 보이게 — «시킨다»는 입력창 타자 → 보내기 → 답이 나옴까지, «답글 단다»는 답글 칸 열림 → 타자 → 등록 → 목록에 달림까지.
13. 페이지 뜰 때 재서 카메라를 정하지 않는다 — 재야 하면 `S.scene(async τ => { if (!M) { await document.fonts.ready; M = 재기 } … })`.
14. 장면은 장면 하나 안에서도 구도를 1~2번 바꾼다(새 숏 — 다른 사진/다른 부분을 탁 띄움, 2번 규칙 지키면서).

**2편에서 바꾼 것(1편과 비슷해 보이면 반려 — 연출설계 3장)**
15. 색: 바탕 콘크리트 #D9DBD6 · 글 #1F2A33 · **주홍 #F05A28 = 우리 가게만 있는 것** · **청록 #1FA39A = AI 가 하는 것** · 회색 #9AA0A6 = 다 똑같은 것. 1편 종이 베이지·코발트·노랑·명조 **쓰지 않는다**. `window.PALETTE` 에 장면 색(3색 안: 바탕 계열·글·강조 하나, 비교는 쪽마다 하나).
16. **«다 똑같은 것»은 회색으로 빠지고(`S.desat(k)` 필터) «우리 가게만 있는 것»만 주홍으로 남는다** — 지우기는 빨강 ✕ 대신 색이 빠짐. 형광펜은 주홍 옅게(`.mk`).
17. 글꼴: 큰 글 `.blk`(Pretendard Black) · 판 글 `.sans` · 라벨 `.lab`(자간 넓은 SemiBold — Mono 금지) · 손글씨 `.hand`(Gaegu) · 앱 `.ui`. 명조·IBM Plex·나눔펜 금지.
18. 구도 기본: **옆 트래킹 · 로우앵글 · 정면 대칭 격자 · 매크로 극접사 · 어깨 너머 · 앞 흐림/뒤 선명 초점 옮기기 · 기울인 판(6~12°)**. 1편 단골(밀고 들어가기·정면 종이판·탑뷰·손에 든 기기 화면·**반반 분할**) 금지. A/B 비교 = 같은 자리에서 A 가 회색으로 빠지고 B 만 색이 남음, 또는 초점 옮기기.
19. UI 는 기기 사진 속이 아니라 **화면 크게 띄운 판을 기울여**(`.slab`·`.app`·`.dk` + `transform: perspective(2200px) rotateX(6~10deg) rotateZ(-4~4deg)`) 콘크리트·감열지·어두운 탁자 위에 얕은 그림자. 기기 사진(초록 화면)은 d04·d11·d36·d51 네 장면만.
20. AI 대화창 = **다크 테마 `.dk`**(사이드바 없음 · 위 탭 줄 · 가운데 대화 열 · 아래 알약 입력창). 빈 대화창으로 시작하지 않는다. 사용자 말 = 오른쪽 회색 말칸, AI 답 = 왼쪽 청록 아바타 + 글. AI 가 쓴 글 중 대표님 말(한 줄)은 주홍 `.or`, AI 가 붙인 말은 청록 `.te` 로 구분하는 장면만.
21. 앱 화면(배달앱 메뉴·리뷰·소식·구인·은행)은 `.app` 흰 판 — 상표·실제 앱 이름·로고 없음, «네이버» 등 글자 금지.
22. 장 번호는 세계 안의 물건에 새긴다(셔터 스텐실 «1»·영수증 인쇄 «2»·테이블 번호 «3») — 1편 «Mono 01 + 명조 제목» 카드 금지.

## 1. 만드는 법
1. `html/s05.html`(본보기)을 복사해 `html/sNN.html` — `<script src="../data/sNN.js">` 번호 바꿈. τ: 0 = 장면 시작(첫 말 −0.25초), `S.SC.dur` = 길이, 앞 `pre`·뒤 `post`(전환 여유) 동안도 그림이 있어야 한다.
2. `S.at()` 으로 시각 표 `T` 를 먼저 만들고 `S.scene(tau => {...})` 안에서 모든 스타일을 τ 의 함수로(transition·animation·setTimeout·Math.random·Date.now 금지).
3. 사진: `소재/sjk02/codex/<이름>.png`(1536×1024) — `S.ph('이름')` 으로 `background-image`. `.photo` 클래스(채도 낮춤). 트래킹은 래퍼에 `S.track(...)`. 확대 최대 1.35배.
   초록 화면 기기 사진(d04·d11·d36·d51)은 `<이름>_clean.png` 를 깔고 화면 UI 는 `소재/sjk02/codex/quads.json` 의 네 점에 `S.fitQuad(el, w, h, quad)`(값은 장면 파일에 복사 — fetch 막힘). 사진+UI 는 같은 래퍼.
4. 렌더: `PYTHONIOENCODING=utf-8 py -3.11 tools/html_motion.py tools/scenes/sjk02/html/sNN.html --sub 1 --workers 3 --out _tmp/sjk02/render --name sNN`
5. 확인(전부 해야 «완료»):
   - `_tmp/sjk02/render/sNN_점검.txt` ERROR 0 (WARN 은 이유 보고).
   - `ffmpeg -v error -i sNN.mp4 -vf fps=1,scale=480:-1 _tmp/sjk02/review/sNN_%02d.jpg` 로 1초 간격 정지 화면을 **Read 로 직접 보고**: 글자 잘림·넘침·겹침·22px 미만 글·빈 화면·자막 자리 침범·UI 원근 어긋남·2초 넘게 같은 화면·2.5초 안 연속 전체 바뀜.
   - `py -3.11 tools/scenes/sjk02/jitter_check.py sNN` → 번갈아 튐 0. `ffmpeg -v error -i sNN.mp4 -f null -` 출력 없음(끝까지 디코드).
6. 사진이 아직 없으면 그 장면은 미루고 다음 장면부터. 사진 속에 글자·로고가 보이면 그 사진 쓰지 말고 보고.

## 2. 공용 부품 (lib)
- `.dk` 다크 대화창: `<div class="dk" style="left;top;width;height">` 안에 `.tb`(`<span class="md"><i></i>AI</span><span class="tab">새 대화</span>`) · `.cv > .col`(`.me` 사용자 / `.ai > .av + .tx`) · `.in`(입력 글 + `.send` 화살표 SVG). 입력창 타자 → 보내기(입력창 비고 `.me` 등장, `type`→`msg_in`) → 답 줄줄이(`S.type`, cps 22~30).
- `.app` 앱 판: `.hd`(화면 이름 — «메뉴»«리뷰»«소식»«채용»«내 통장» 같은 일반 말) · `.row`(사진 `.th` · `.nm` 이름 · `.pr` 가격 · `.ds` 설명 · `.st` 별점 · `.av` 프로필 이니셜 · `.rp` «사장님 답글» 상자 · `.bdg` 배지).
- `.sheet` 스프레드시트 · `.thermal` 감열지(흰 띠 600px 폭, 위아래로 길게) · `.chip.or/.te/.gr/.ink` 칩 · `.mk` 주홍 형광펜.
- `S.focus` 부각 · `S.camState/camCss` 카메라 키 · `S.desat(k)` 탈색 필터 · `S.track` 옆 흐름 · `S.ph` 사진.
- 셔터 내림(장면 안): 셔터 사진(p01·p56·p03 등)을 위에서 내려오는 마스크(`clip-path: inset(0 0 ${100-k*100}% 0)`)로 덮는다 — 셔터 사진 자체가 «물건»이라 도형 아님. 장면 사이 셔터 전환은 조립기가 한다.
