## 공통 규칙
1. **흰 종이·흰 판·흰 바닥 금지.** 바꾸는 재료(장면 성격에 맞는 것 하나):
   - **화면 UI(차트·목록·통장·댓글·설정·리뷰 카드·앱 메뉴 카드)** → 어두운 판. 바탕 #1A1F25, 테두리 1px #2C343C, 반경 14, 글 #ECEEEF, 보조 글 #A3ACB4, 구분선 #262D34, 강조 청록 #1FB596 · 주황 #F0602A · 회색 막대 #5E6670. 불투명(알파 255). `.dk`(AI 채팅 판)와 같은 결로 맞춘다.
   - **사진 속 실물 종이 소품** → 그 물건이 실제로 가진 색·재질: 노란 먹지 주문서, 형광 포스터(노랑·빨강·주황·연두), 색 포스트잇(노랑·민트·분홍, 살짝 바랜 톤), 크라프트지(#B98C5E 계열), 노란 리걸 패드(#F1E3A6 + 파란 줄), 마스킹 테이프(#E5D3A6, 반투명·찢긴 끝), 검은 칠판·검은 아크릴 판(#1E2124, 분필/흰 글). 평평한 단색 직사각형으로 끝내지 말고 **결(질감)·그늘·가장자리**를 넣는다 — 질감은 `소재/sjk02/codex/t_*.png` 나 CSS 노이즈(SVG feTurbulence 필터, 은은하게)로. 도형으로 새 사물을 흉내 내지는 않는다(재질만 바꿈).
   - 영수증·감열지(s24·s48·s51)는 실제로 흰 종이라 그대로 둔다.
   - 블렌더 흰 바닥·흰 탁자(s17 coins.py, s45 tower.py) → 어두운 재질(짙은 호두나무 탁자 또는 짙은 콘크리트, 세상 배경도 어둡게)로 바꾸고 해당 프레임만 다시 렌더.
2. 글 대비: 어두운 판 위 글은 밝게, 밝은 색 소품 위 글은 짙게. 글 크기는 줄이지 않는다(≥ 28px, 이름표 ≥ 44px — 기존 10-20 규칙 그대로).
3. **표시(동그라미·타원·밑줄·테두리)는 대상에 정확히 맞춘다.**
   - 대상이 HTML 글·요소면 손으로 잰 좌표 금지 — 실행 중 대상의 `getBoundingClientRect()`(같은 부모 좌표로 환산)에서 경로를 만들어 사방 여백 10~16px 로 감싼다. 밑줄은 글 아래 6~12px, 글 폭과 같게.
   - 대상이 사진 속 사람·물건이면 사진 원본을 직접 열어(Read) 머리끝~발끝/물건 끝을 재고, 머리·손·발이 **전부** 안에 들어오게 사방 6% 이상 여유. 카메라가 움직이면 같은 카메라 변환 안에 둔다.
   - 확인: `PYTHONIOENCODING=utf-8 py -3.11 tools/marker_sheet.py _tmp/sjk02/render _tmp/sjk02/selfqa/mk_new sNN` → 나온 판을 Read 로 직접 보고 «글자를 가르거나 비켜 감 0, 대상이 다 들어옴»을 확인.
4. 효과음 신호(S.ev 이름·뜻·시각)는 그대로. 시각을 바꿨으면 보고에 적는다.
5. 절대금지 유지: 흔들기·단색 배경판·말 따라 쓰는 화면 글·«사장님»·«»·«남는 돈/남은 돈»·구석 작은 이름표·전체 화면 레이어 `data-box`.
6. 고친 뒤 장면마다:
   - 렌더 `PYTHONIOENCODING=utf-8 py -3.11 C:/Users/user/Desktop/한비즈-롱폼자동화/tools/html_motion.py C:/Users/user/Desktop/한비즈-롱폼자동화/tools/scenes/sjk02/html/sNN.html --sub 1 --workers 2 --out C:/Users/user/Desktop/한비즈-롱폼자동화/_tmp/sjk02/render --name sNN` → 규칙 점검 ERROR 0
   - `PYTHONIOENCODING=utf-8 py -3.11 tools/screen_text_audit.py tools/scenes/sjk02/html/sNN.html` ERROR 0
   - `py -3.11 tools/scenes/sjk02/review_sheet.py sNN --n 8` → `_tmp/sjk02/review/sNN_rv.jpg` 를 Read 로 직접 보고: 흰 종이/흰 판 없음 · 글 읽힘 · 판 잘림·겹침 없음.
   - 표시가 있는 장면은 3번의 marker_sheet 확인.
7. Bash 에서 `cd` 금지(절대 경로). 커밋 금지. 맡은 장면 파일 + 맡은 블렌더 스크립트 말고는 고치지 않는다(`lib/` 금지). 조립·믹스는 설계자가 한다.
