# 성제관03 실물 층 실행자 지침 (설계자 → 실행자)

너는 «성제관03» 유튜브 롱폼(1920×1080·59.94fps, 배달앱 수수료 편)의 **실물 층 장면 HTML**(Codex 사진 + 재현 화면)을 만들고 렌더·확인하는 실행자다. 판단은 설계자가 했다 — 명세대로 만든다.
저장소 루트: `C:\Users\user\Desktop\한비즈-롱폼자동화`. **셸에서 `cd` 절대 금지**(훅이 막혀 모든 명령이 멈춘다) — 항상 절대 경로. 파이썬은 `py -3.11`, 앞에 `PYTHONIOENCODING=utf-8`.

## 먼저 전문으로 읽기
1. `핸드오프/2026-10-23_성제관03_배달앱수수료/20_연출표.md` — 1장(두 층 규격·색·출처 줄·재현 화면·계산 숫자) + 2장 표의 맡은 장면 행.
2. `tools/scenes/sjk03/SPEC.md` 전문(특히 2장 실물 층 · 3장 사진 이름).
3. `tools/scenes/sjk03/lib/sjk.css` · `lib/sjk.js` · `lib/e4.js` · 본보기 `tools/scenes/sjk03/html/s02.html`(구조).
4. 맡은 장면의 `tools/scenes/sjk03/data/sNN.js`(줄·어절 시각 — τ 기준).
5. 사진은 `소재/sjk03/codex/` — 맡은 장면 사진을 **Read 로 먼저 직접 보고** 물건이 어디 있는지 확인한 뒤 얹을 자리를 정한다. 사진 크기 1536×1024 → 판에 cover 로 깔면 가로 1.25배·위아래 100px 잘림(판 좌표 = 사진 좌표 ×1.25, y −100).
6. 초록 화면 기기 사진(d..)은 `<이름>_clean.png` 를 깔고 `소재/sjk03/codex/quads.json` 의 `stage` 네 점(왼위·오위·오아래·왼아래 순서라고 적혀 있지만 **기기가 기울면 순서가 돌아갈 수 있다** — 사진을 보고 화면 위쪽이 어디인지 확인해 맞는 순서로 넘길 것)에 `S.fitQuad(el, w, h, quad)`. 화면 UI 가 엄지를 덮는 건 괜찮다.

## 꼭 지킬 것(이번 편)
- **화면·재현 화면 어디에도 «사장님» 글자 금지**(절대금지 — 앱 이름표는 «가게 관리» «내 가게» 같은 일반 말). «남는 돈·남은 돈» 금지. 실제 앱 이름·상표·로고 금지. 가게 이름 ○○, 전화 010-0000-0000.
- 화면 글은 연출표·녹음 원고(`핸드오프/…/10_분석/녹음원고.md`)에 있는 말·숫자만. 숫자가 필요 없으면 막대·눈금으로.
- 사진 위 숫자는 `.dpan` 하나. 사진 위 구석 이름표 칩 금지. 말풍선·«» 대사 금지. 흔들기·왕복 흔들림 금지.
- 사진만 천천히 움직이고 아무 일도 없는 구간 2초 넘게 금지 — 연출표 행의 «무엇이 언제»를 말 시각(`S.at`)에 맞춰 넣는다(선 그어짐·판 들어옴·화면 바뀜·눌림 고리·숫자 등). 효과음 계기 `S.ev` 1.5초에 1개 안팎.
- 연출표 «2.5D»·«천천히 밀기»는 `#ph` transform 의 아주 느린 1.00→1.08 / 옆 흐름 translateX ±40px.
- 사진 속 종이(정산서·쪽지·메모)에 얹는 HTML 종이는 사진 속 종이 자리·기울기에 맞춘다(Read 로 본 좌표). 사진 속 종이가 없으면 HTML 종이 카드를 사진 위에 놓인 것처럼(얕은 그림자·살짝 기울기).

## 각 장면 할 일
HTML 작성 → 렌더 `PYTHONIOENCODING=utf-8 py -3.11 tools/html_motion.py tools/scenes/sjk03/html/sNN.html --sub 1 --workers 2 --out _tmp/sjk03/render --name sNN` → `_tmp/sjk03/render/sNN_점검.txt` ERROR 0(겹쳐야 하는 건 같은 data-box-group, 풀블리드 사진은 data-box 없이) → 정지 화면을 **파이썬 subprocess 로 ffmpeg 호출**해 1초 간격(scale 640) `_tmp/sjk03/review/<너의 글자>/sNN_*.jpg` 로 뽑아 **Read 로 전부 직접 본다**(bash 에서 한글 경로로 ffmpeg 를 직접 부르면 «Illegal byte sequence» 로 깨진다) → 고칠 것 고쳐 다시 렌더 → 다음 장면.
볼 것: 얹은 UI·종이가 사진 속 물건 자리에 맞는지(원근·크기) · 글 잘림·겹침 · 2초 넘게 같은 화면 · 자막 자리(y 965 아래 가운데) 침범 · 사진 속 글자·로고·얼굴.
