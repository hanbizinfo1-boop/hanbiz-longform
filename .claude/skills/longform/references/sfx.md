# 효과음 — 문법 · 크기 · 고르기 · 반복/빈 구간 · 검사 (롱폼)

> 원본: `D:\영상제작\길라잡이\효과음-브랜드홍보-원칙.md`(0장 문법 · 0-2 파일별 크기 · 0-5 고르기) + `예능효과음-등급.md`·`예능효과음-라이브러리.md`(요약) + `후킹애펙-워크플로우.md` 3장. 분양 쇼츠 전용 내용(분당 77개, 분양4 이력)은 뺐다.
> 효과음 기준값(크기·반복·고르기)의 «한 곳»이 이 문서다. 음원 파일은 이 폴더에 복사하지 않았다 — 경로는 `tools/config.py`(`SFX_LIB` · `SFX_LIB_OWNER` · `SFX_LIB_SCENE`).

## 핵심 (먼저 읽기)

- **효과음은 컷이 아니라 «그래픽 등장 프레임»에 붙는다**(사장님 강의 편집 실측 97%). 컷마다 전환음을 깔면 «너무 같은 효과음이 많이 들어가 / 정합성도 안 맞아»로 반려됐다(09-22).
- **기준은 실측이다.** 사장님 마감본이 1순위 레퍼런스. 웹 글·감으로 «톤»을 정하지 않는다(10-01 «만화 계열 빼기»는 사장님 실제 편집과 반대라 10-02 폐기).
- **뜻·그림에 맞춘다**: 조건·기준에 축하음 금지, 도장엔 `도장.mp3`, 게이지·밑줄엔 차오르는 소리.
- **크기는 3장 파일별 표가 우선**(프리미어 0dB = 0.17783). 표에 없는 파일은 구울 값 +5dB.
- **자연 길이**(잦아드는 데까지, 최대 2.5초, 끝 0.25초 페이드). 빈 구간 2.5초는 «소리가 실제로 안 나는 시간». 같은 소리 바로 연달아 금지, 번갈아도 3초 안에 같은 파일 3번까지.
- **청음본·A/B 듣기를 요청하지 않는다**(10-02 «청음본 들을 시간이 없어, 실사용에서»). 실제 편에 넣어 드리고 반응(두심/빼심)을 `tools/data/예능효과음-실사용.json` 에 적는다.
- **소리는 귀로 못 들었으면 «못 들었다»고 보고한다.**

## 1. 영상 성격으로 밀도를 정한다 (0-1)

배경음악을 까는 편집이면 효과음도 촘촘하게, 토크·해설이면 효과음도 거의 없게 간다. 둘은 같이 움직인다.

| 우리 작업 | 닮은 레퍼런스 | 효과음/분 | 배경음악 |
|---|---|---|---|
| 정책자금 강의 | 놀면뭐하니·네고왕 정보 장면 | **사장님 재무제표 강의 4.6** | 사장님 편집대로 |
| 화면녹화 설명(메타 DB 광고 세팅법 본편 등) | 슈카월드(효과음 거의 0, 펜 강조) · 문명특급 정보 장면(카드 한 장마다 틱) | 자료 카드·코너 전환에만 | 거의 없음 |

- 강의 재무제표2강(16분): 효과음 **12.9초당 1회(분당 4.6)** · 12종 · 상위 3종(도장·휙２·띠딩2)이 77% · 그래픽 97%에 효과음이 붙음.
- 정보 예능 쪽 실측(신비한 건축사전 8편): 분당 4.4~15.5 · 길이 0.15~0.25초 · 표시·글자에 붙는 소리만 +7~+10dB · 통합 음량 −14~−16 LUFS · **트루피크 −1.5dB** · 클리핑 0.
- 다큐식 «절제»(분당 0.2~1.1)는 우리 문법이 아니다.

## 3. 크기 — 한 곳

### 3-1. 프리미어 볼륨 저장값 읽는 법 (함정)

**0dB = 0.17783**(+15dB 여유) → dB = 20·log10(v ÷ 0.17783). 1.0 은 +15dB. 1.0 을 0dB 로 읽으면 올리신 걸 «내리셨다»고 거꾸로 읽는다(10-07 «나는 볼륨을 키웠는데 왜 넌 −라고 하니»). 강의 자료04 v1 은 반대로 0.1778 을 −15dB 로 읽어 15dB 작게 냈다(«네가 준 거 너무 작아»). 환산: `tools/lecture_edit_profile.py` `ZERO_DB`. 사장님 타임라인 **목소리(A1)는 +7dB** → 들리는 크기(목소리 대비) = 구울 값 − 7.

### 3-2. 기본 크기 (표에 없는 파일은 구울 값 +5dB = 들리는 크기 −2dB)

- **기본 = 목소리 대비 일반 −2dB · 휙 −3dB · 펜·필기 −8dB**(10-02 사장님 최종값, 완료본 역산 — 「+3dB」 지시를 1dB 넘게 잡았다가 내리신 이력). 큰 강조 자막 쿵·쾅만 목소리보다 크게.
- `FILE_DB_DEFAULT = 5`(`tools/bisa_meta_sfx.py`) — 06 에서 사장님이 전부 +3 올리셔서 +2 → +5.

### 3-3. 파일별 크기 (10-07 사장님 «이 효과음 쓸 땐 데시벨 이렇게 해 줘» · «이번 것도 데시벨 조정했어») — 기본값보다 우선

목소리 **원음** 대비 «구울 값» = 구운 값 + 사장님 클립 볼륨. 같은 파일이 여러 장면에 나오면 **가장 최근 장면 값**. 도구는 `tools/bisa_meta_sfx.py` `FILE_DB` 가 자동 적용한다.

읽는 법
- 사장님은 **늘 올리셨다**(04 +8~+12, 05 +4~+11, 06 2판 +3~+6). 구울 값을 올릴수록 올리시는 폭이 줄어 이제 «+3» 근처. 06 에서 **전부 +3** 이라 표에 없는 파일 기본도 **+5dB**.
- **단계 글·칩 등장(pep)은 더 크게**(+6 더) — 글이 하나씩 붙을 때 «톡» 소리가 잘 들려야 한다.
- 예외: 05 «확대» 휙２ 는 16:19 에 0dB 로 **내리셨다**(원음 −6). 녹화 화면 확대엔 휙을 작게, 판이 통째로 들어오는 전환엔 크게.
- 같은 파일도 04(화면 시연)가 05(설명)보다 크다. 지금은 최근(06) 값을 쓴다. 마무리 소리(체크 칩·확대 풀림)는 조금 크게, 반짝은 가장 작게.
- 장면 도구(`bisa_*.py`)의 `SND_FIX` 크기는 만들 당시 값 — 새 도구는 이 표를 따른다.

## 4. 고르기 — 등급표 · 라이브러리 · 통과한 소리

### 4-1. 등급표 (`tools/data/예능효과음-등급.json`, 원본 요약 `D:\영상제작\길라잡이\예능효과음-등급.md`)

- 분류마다 **A★(사장님이 실제 쓰신 소리) → A → B** 순서로 고르고, 맞는 게 없을 때만 다음 등급으로 내려간다. 사장님 라이브러리까지 한 표에 넣었다. `tools/bisa_meta_sfx.pick(cat, n, skip, new)` 가 이 json 에서 고른다.
- 점수 = 길이 적합 0.3 + 밝기 적합 0.25 + 소재 상태 0.2(sfx_check) + 예능 효과음과의 소리 닮음 0.25(보조). 소리 닮음의 한계: 계열 가려내기 정확도가 뿅 56 · 띵 54 · 쿵 48 · 휙 43 · 반짝 34%(찍기 10%) — 닮음만으로 매기면 사장님 주력 뿅·휙２가 C로 나와서 주 기준에서 뺐다.
- **등급은 소리 «결»만 본다 — 뜻은 모른다.** 목차 카드에서 밑줄에 «잔 부딪힘», 업종 칩에 «카메라 셔터»가 1순위로 뽑힌 적이 있다. 그래서 **역할마다 파일 이름으로 고정**한다(`SND_FIX`).
- **실사용 json 이 등급을 덮어쓴다.** 사장님이 그대로 두신 소리는 `통과`(A★), 빼거나 바꾸라 하신 소리는 `반려`, 자리가 안 맞았던 건 `장면반려`(소리 전체가 아니라 그 자리). 01 에서 통과한 블록소리·キラッ・高速移動・두꺼운 바람이 02 1판에서는 «별로»였다.
- **사장님 소리와 새 소리를 섞는다**(10-02 «가지고 있는 것에서만 하다 보니 아쉽다»).
- 연타 자리(카드 여러 장 등): 같은 분류 A 안에서 결이 비슷한 다른 파일을 돌려 쓴다.
- 파일 이름 앞 `ML_` = Mixkit · `KN_` = Kenney · `SEL_` = 効果音ラボ(`SFX_LIB`), 앞말 없는 것 = 사장님 라이브러리(`SFX_LIB_OWNER`, 한글 파일명이 NFD 일 수 있어 NFC 로 정규화해 찾는다 — `bisa_toc_cards.by_name`). `모음1~6`(게임·방송 음원)은 쓰지 않는다.

## 6. 타이밍 (0-3)

- **말 위에 얹는다.** 67%가 말하는 중에, 19%가 말 끝 직후에 붙었다. 말을 멈추고 효과음만 들려주는 경우는 드물다.
- 자막/그래픽이 뜨는 **그 프레임**에 맞춘다. 펀치라인·반전 뒤라면 0~0.5초 안에.
- **음악 끊김**: 반전·태세 전환·당황·웃음 직후 0.35~0.85초 동안 배경음악을 11~27dB 뚝 뺀다. 빈자리에 다음 말이나 효과음을 받는다. 촘촘형 채널은 분당 1~3번.
- 배경음악은 «빼기»가 가장 큰 장치: 숫자 공개·반전·결론·이름 공개 직전 0.5~2초 뚝 끊고(−9~−24dB). 펌핑 덕킹은 쓰지 않고 처음부터 목소리 밑 높이로 고르게 깐다. 곡이 바뀌는 자리 = 이야기 국면이 바뀌는 자리.

## 8. 믹스 · 마스터

- 믹스 순서: 목소리 → 음악 버스(5kHz 위 −4~−6dB 셸빙, 2~4kHz 2~3dB 비켜 주기) → 현장음 → 효과 버스 → 마스터(**트루피크 −1.5dB 리미터**).
- **목소리를 덮지 않는다.** 목소리보다 크게 치는 것은 강조 자막 한 순간(0.1~0.4초)뿐.
- 이어 붙인 자리의 치찰음(ㅆ)이 AAC 인코딩 뒤 +3.7dB 튀어 클리핑된 적이 있다 → 무음 가운데서 자르기 + 짧은 페이드 + 16kHz 위 컷 + 리미터.
- 현장음은 장면이 바뀔 때 1~6초만 깔고 음악 밑으로 사라지게 한다.
- 미리보기: 목소리 +7dB 로 섞어 사장님 타임라인과 같게. ebur128 로 음량·트루피크(−1.5dB 이하) 확인.

## 9. 학습 루프 (새 레퍼런스를 재야 할 때)

```
고르기 → 받기 → 기계로 재기 → 사람이 정독(눈+귀) → 비교표(레퍼런스 ↔ 우리) → 규칙(번호·근거·검사법)
 → 검사 도구 → 만들기 → 완성본 다시 재기 → 사장님 청취 → 회고 → 규칙 고침 → (다음 편)
```

- 같은 결의 채널 3~5개 × 조회 상위 3~10편, **채널 중앙 조회 대비 배수**로 «잘된 편» 선택. **1순위 레퍼런스는 사장님 본인 편집.** 받을 때 403·봇 차단은 우회하지 않는다. 무거운 분석은 한 번에 하나씩(동시에 돌리면 메모리가 넘쳐 렌더가 죽는다).
- 규칙 양식: `ID · 규칙 · 확인 방법(숫자) · 나쁜 예→좋은 예 · 근거(채널·편 수) · 유래(사장님 원문)`. 숫자는 범위로. 옛 규칙은 지우지 말고 «폐기(날짜·이유)».
- **함정**: 고친 척(짚은 한 곳만 고침) · 한 채널·한 출처로 규칙화(최소 3채널) · 원인을 쪼개지 않고 고치기 · 측정하지 않은 숫자를 기준처럼 쓰기(모르면 «미확인»).
