## 3. 잘 된 것 — 근거 있는 패턴

1. **«숫자 반전 + 사례»가 쇼츠 1위**: «NICE 350점인데 5천만원 승인??»(65,390) — 낮은 신용이라는 상식과 큰 금액의 대비, 의심하던 고객의 반응(«사기치지 마»)까지 30초 안에. 2위 «정책자금 사기 90%는 이 불법 수수료에서»(10,123) — **경고·손해 회피**.
2. **비유 한 개로 이해시키기**: 스타벅스 기프티콘(쓸 수 있는 곳이 정해진 돈) · 용달 이사(10만 원 아끼다 80만 원 수리비) · 진단서 허위 기재(당장 받고 다음이 막힘). 이 비유 장면이 쇼츠로 잘려 1,600~1,800회.
3. **«틀린 정보 바로잡기» 후킹**: «유튜브에 나온 숫자 다 틀렸어요»(여성 지원금) — 권위·신뢰 소구가 이 채널 결.
4. **고객 후기 = 채널 최고 롱폼**(3,400): 화려한 성공담이 아니라 «안 된다는 말만 듣던 세 분»·«처음엔 사기인 줄» — **의심 → 신뢰 → 결과** 순서.
5. **질문 목록형 쇼츠**(«내 상황에 맞는 정책자금 30초 정리» — Q.신용이 낮다면 / Q.담보가 없다면 …): 자기 상황 찾기 욕구, 저장각.

## 4. 약한 것 — 새 형식이 고칠 곳

- **롱폼이 안 보인다**: 정면 토크 한 컷을 5분 — 화면 변화가 말 내용을 따라가지 않는다(일러스트는 몇 장, 대부분 얼굴). 썸네일·첫 5초가 약하다(편마다 형식이 달라 채널 얼굴이 없다).
- **자막 오인식**이 자동 자막 수준(«성재관»·«무의자»·«정찰자금») — 외부 검수에서 오탈자가 걸린 이력과 같은 문제.
- **AI 소구는 1편뿐이고 «툴 따라 하기»**(클로드 연결 방법 화면 녹화) — 사장님 대상(소상공인·대표님)에게 «AI 가 내 사업에 뭘 해 주나»를 보여 주는 이야기가 없다.
- **CTA 가 편마다 다름**(구독=입장료 · 댓글에 «성제관» · 오픈채팅 · 전화 상담 · 홈페이지) — 하나로 모이지 않는다.
- 소리 크기 들쭉날쭉(LUFS −7 ~ −21).

## 5. 새 형식(목소리만 + 연출)에 가져갈 것 — 설계 메모(아이디어 단계의 근거)

- **채널 정체성은 «성제관 = 돈 되는 정보를 쉽게 전시하는 관»**(영상 안 표현 «미술관·박물관 돈 내고 가시죠? 성제관은 돈 되는 정보를 무료로 24시간 전시» · «입장료는 구독»). 사람이 안 나오면 이 «관(전시관)» 세계관을 **화면 장치**로 살릴 수 있다 — 매 편 «전시실 입장» 오프닝, 정보 = 전시물(액자·유리 진열장 위 카드).
- **이해 → 몰입 → 공감**을 기존 성공 패턴에 맞추면: 이해 = 비유 한 개를 그림으로(기프티콘·용달·진단서처럼) / 몰입 = 숫자 반전·손해 회피 후킹(350점→5천만) / 공감 = 사장님 상황 재현(«통장은 늘 빠듯했다» · «처음엔 사기인 줄»).
- **쇼츠가 성장 엔진** — 롱폼 한 편을 기획할 때 쇼츠 3~5개가 잘려 나오게 장면을 짠다(비유 장면·사례 장면·경고 장면이 각각 30초 완결).
- **AI × 컨설팅 소구 방향 후보**: «AI 로 사업계획서 초안 → 컨설턴트가 고치는 것»처럼 **AI 가 할 수 있는 것 / 사람(컨설팅)이 해야 하는 것**의 경계를 보여 주면 두 소구가 한 편에 묶인다(«AI 는 무료, 그런데 왜 컨설팅에 돈을 내나» = 기존 수수료 영상 질문의 AI 판).
- 기존 자료 재활용: 정책자금 정보 자체는 쌓여 있다(정석 시리즈 6강) → 같은 정보를 «목소리 + 연출»로 다시 만들어 비교 실험 가능.
- 제작 조건: 제작 컴퓨터에서 **AE 없이**(compose·html·design·Codex 이미지) — 파트너센터 본편에서 쓴 실화면 확대·카드·로고·붓 획 + 쇼츠광고 세션의 타이포·HTML 모션 자산.
