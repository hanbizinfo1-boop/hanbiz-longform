## 4. 사장님 작업 방식 — 자동 모드 운영에 반영

| 관찰 | 반영 |
|---|---|
| 선택·볼륨은 **말보다 프리미어 저장본으로 먼저** 알린다(시안 C 선택, 효과음 +8~+12dB, 효과음 직접 추가) | ⑨배우기 첫 단계 = **아침 저장본 diff 읽기**(볼륨 → `FILE_DB`, 바뀐 컷, 지운 장면) |
| 통과 표현: «통과 다음» «오케이 다음» «좋아» «통과 다음꺼 고고» «너무 이제 괜찮은수준» · **«일단 이건 통과 근데 …»**(통과 + 새 규칙) | 통과 사전 + «근데» 뒤는 새 규칙으로 기록 |
| «수정x 다음편부터 적용» — 소급 금지 | 새 규칙은 이미 낸 장면을 고치지 않는다(지시 없으면) |
| 추천을 따르지 않을 때가 있다(02 ③ 추천 → ④, 11 3판 B 추천 → C) | 검수표에 차순위 2개를 늘 같이 보여 준다 |
| 질문형 선호는 번복될 수 있다(«흰 판 꼭 넣어야 해?» → «넣고 진행») | 지우는 변경은 플래그로 분기해 되돌릴 수 있게 |
| 오타·구어체가 많다(«종류예약»=종료예약 · «목차카트»=목차카드 · «폴어뎡러오바»=폴더 열어봐) · 잘못 보낸 메시지가 온다(10-12 «잘못보냈다») | 오타는 뜻으로 복원, 직후 «잘못보냈다»면 앞 메시지를 반영하지 않는다 |
| 블러·전환·배속·AI 전환·자막 오탈자·PIP 마스크·렌더 내보내기는 사장님이 직접 | 자동 모드도 자막·컷은 손대지 않는다. 사장님이 원문에 건 흐림은 다시 쌓을 때 그대로 재현 |
| 외부 피드백은 사장님이 붙여 넣는다(«이거 클로드 코드한테 보내줘도 될듯») | 검수 입력 칸: 장점 = 보존 목록, 단점 = 수정 목록, 오탈자 = 사장님 몫 |
| 긴 작업은 중간 상태를 짧게 알려 주면 좋아한다 · 폴더는 묻지 말고 연다 · 커밋은 요청할 때만 | 그대로 |
| 무인 작업의 실제 제약 = **사용량 한도**(10-02 03:09 한도로 멈춤) | 밤샘 러너는 단계마다 `state.json` 저장 → 끊겨도 이어 감 |

  1. 연출표 효과음 칸에 **뜻(긍정/부정/중립)** 과 **그림 종류**(도장·체크·타자·게이지·전화·페이지…)를 반드시 적고, 역할→파일 고정표(`SD-01`)에서만 고른다. 등급표는 «결»만 안다.
  2. 새 합성음·외부 다운로드 금지(허락 없이) — 사장님 라이브러리·등급표 안에서만.
  3. 글을 지워 빈 구간이 생기면 소리를 끼우지 않고 **그 말에 맞는 그림 동작**을 하나 더(11 3판).

  5. 보고·검수표에 «소리는 듣지 못함»을 항상.
