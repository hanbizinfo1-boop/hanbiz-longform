# 6. 4채널 공통 규칙 후보

1. 제목은 `대상 + 숫자/시간 + 즉시 실행 약속` 한 줄로: 혼잡스 `(500만원 쓰고 검증했습니다)`, 알린 `개꿀팁 11가지`, 이동훈 `10분만에/딱 15분만에`, 신영선 `5가지 핵심 기능 8분 총정리`.
2. 훅 0~30초 안에 결과·문제 중 하나를 먼저 보여준다. 결과 먼저: 알린 hFlf 0:00(한 줄로 5개 작업), 파이어플라이 0:00(전후 비교), 젠스파크 0:00; 이동훈 코워크 0:00~0:45(하이라이트 클립); 혼잡스 돈 5가지 0:00(통장에 들어온 방법). 공감 상황: 알린 토큰 0:00, 이동훈 코덱스 0:00.
3. 훅 직후 "무엇을 얻는가"를 1~2문장으로 못 박고 "끝까지" 예고: 알린 6E5K 0:15·젠스파크 0:45, 혼잡스 돈 5가지 0:15~0:30, 이동훈 루프 0:15~0:30(A부터 Z까지), 이동훈 코워크 1:45(끝까지 보시면).
4. 개념은 정의 한 줄 + 일상 비유 1개를 영상 전체에 끌고 간다: 혼잡스 용어 12개 = 신입 직원(전체), 이동훈 루프 = 에어컨 온도계 + 신입 6개월(2:00~8:30), 알린 코워크 = 헌법/하위법(3:15), 알린 토큰 = 카톡(2:30).
5. 항목형 영상은 번호 호명 + 챕터 타임라인으로 위치를 계속 알려준다: 알린 6E5K 팁 1~11, 혼잡스 용어정리 "이제 마지막 12번째"(7:50), 이동훈 코워크 1~6, 신영선 전편 `0:00 미리보기`부터 `오늘의 요약`까지.
6. 시연은 "프롬프트 -> 결과물 열어 확인"을 한 세트로 보여준다: 알린 hFlf 9:15 캘린더·임시보관함 열기, 이동훈 코덱스 5:15 배포 URL 클릭, 신영선 어사이드 10:45 발행 완료 확인, 신영선 이미지 9:15 수정 전후 비교.
7. 훅 문장을 본편 후반에 한 번 더 말하는 수미상관: 알린 hFlf 0:00=9:30, 파이어플라이 0:00=4:45=7:00, 젠스파크 0:00=9:15. 시작 문제로 돌아가는 형태는 이동훈 코덱스(0:00 한도 -> 10:45).
8. 한계·위험·비용을 직접 말해 신뢰를 만든다: 혼잡스 제브 1:30("진짜 제브는 내 컴퓨터에 못 넣습니다"), 이동훈 바이브코딩 11:45("절대 만능이 아닙니다"), 신영선 그록봇 5:00(미국 IP 페널티)·10:15(직장인에게 비쌈), 신영선 어사이드 7:50(알고리즘 리스크), 알린 워크 1:30(모드만 바꾼다고 똑똑해지지 않음).
9. 숫자·날짜·출처로 근거를 박는다: 알린 토큰 3:15(98.5%), 이동훈 코덱스 0:15(3월 31일 앤트로픽 공식 인정), 혼잡스 제브 0:00·1:30(9월 15일 출시, 9월 29일 기사), 혼잡스 돈 5가지 2:23~5:45(53,000건·4억·10억).
10. 반론을 먼저 꺼낸다(시청자 질문 대역 포함): 알린 hFlf 1:00("너무 어려운 거 아니야?"), 신영선 이미지 3:15·6:15(가상 질문), 신영선 어사이드 7:45(알고리즘 댓글 예상), 혼잡스 ZOTD 3:45("갑자기 무슨 햄버거 가게냐고요?").
11. 같은 흐름의 구조를 각 항목에 반복해 학습 비용을 줄인다: 혼잡스 돈 5가지(사례 숫자 -> 왜 팔리나 -> 클로드로 하는 법 -> 꿀팁), 알린 토큰 팁(행동 -> 손해 -> 해법 -> 예시), 알린 워크(프롬프트 -> 파일 업데이트 -> 실제 작업).
12. CTA는 영상 말미 1개 행동 + 자료 허브: 알린 3개 영상 4:00·7:30·3:30 "더보기·고정 댓글 무료 자료", 이동훈 루프 9:30 "첫 루프 업무를 댓글로", 혼잡스 제브 8:15 "하고 싶은 일 댓글", 신영선 14:00 "무료 강의 날짜". 구독 요청은 15초 미만의 한 줄로(혼잡스·이동훈 코워크·신영선 그록봇).
13. 마지막에 N줄 요약 + 다음 행동 3개: 혼잡스 제브 7:49~8:15("오늘 바로 할 3가지", "딱 세 줄"), 이동훈 코워크 10:19(3가지 정리), 신영선 전편 요약 챕터.
14. 시리즈·다음 편 예고로 재방문 연결: 혼잡스 용어정리 9:15·1인 기업 7:15, 신영선 헤르메스 17:45(프랜차이즈 시리즈), 알린 hFlf 0:15(지난 코워크 영상과 연결), 이동훈 코덱스 마무리.
15. 길이는 8~12분에 모으고 챕터 5~12개: 4채널 19편 중 14편이 8:00~12:31. 가장 높은 조회는 8~9분대(혼잡스 8:04 397K, 신영선 8:12 74K).
16. 설명란: 상단 링크 블록 + 타임라인 + 해시태그 + 무료 자료 허브. 광고·제휴는 `#ad`/제휴 링크 최상단(알린 파이어플라이·젠스파크).

# 7. 조회수 높은 편 vs 낮은 편 차이

### 혼잡스
- 상위: 돈 5가지 397K(8:04), 용어 12개 259K(9:29), 1인 기업 119K(8:01). 하위: 제브 로컬 설치 26.6K(8:30).
- 차이: ① 상위 = 대중이 이미 궁금한 질문("뭘로 돈을 버나", "용어가 어렵다") + 숫자 목록 + 비유 / 하위 = 신제품·낯선 이름(제브/라야) + 설치 명령어 중심(개발자 대상). ② 상위 = 결과가 "돈·이해" 같은 삶의 가치, 하위 = "내 PC 속 모델 학습" 같은 기술 가치. ③ 훅: 상위는 "500만 원 검증" 같은 개인 체험 수치, 하위는 제품 소개 + 날짜 나열. ④ 상위 3편은 번호/단계 목록이 명확, 하위는 설명이 직렬이고 전문용어(MLX, docker compose)가 많음. ⑤ 길이는 비슷(8분대)이라 길이 차이가 아니라 주제 보편성 차이.

### 알린 ALINN
- 상위(추정 순): 젠스파크 24.97M[이상치], 워크 모드 293K, 파이어플라이 287K[좋아요 42 이상], 클로드 토큰 189K. 하위: 코워크 심화 시스템 31K(영문 제목).
- 차이: ① 상위 = 주류 도구(ChatGPT·Claude)의 "숨은 기능/아끼는 법" 같은 즉시 효용 + 손해 회피 훅("30%도 못 쓴다", "잘못 사용하고 계세요"). ② 상위 2편(젠스파크·파이어플라이)은 제휴/광고성으로 "신기능 소개 + 결과 선공개 + 이벤트/링크"가 결합. ③ 하위(코워크 심화)는 개념(규칙·메모리·작업 공간)을 먼저 쌓는 구조라 훅 이후 이탈 구간이 길고, 제목이 영문(번역 제목)이라 국내 검색 노출이 약했을 가능성(추정). ④ 길이: 상위 9~12분, 하위 약 10.5분으로 큰 차이 없음. ⑤ 데이터 신뢰도 주의: 조회·좋아요 불일치 2건.

### 이동훈의 루트AI
- 상위: 루프 엔지니어링 330K(9:51), 코워크 A to Z 306K(11:52), 바이브코딩 234K(14:22), 코덱스 191K(11:22). 하위: 클로드 디자인 PPT 34K(8:01).
- 차이: ① 상위 = 업계 이슈(앤트로픽 책임자 발언, 주가 하락, 한도 논란)와 연결된 개념·툴 입문 + "10분/A to Z/15분" 압축 약속 + 권위 인용(유퀴즈·앤트로픽). ② 하위 = 특정 기능 한 가지의 업데이트 튜토리얼(디자인 시스템·PPTX 변환)로 대상이 좁고 훅이 "결론 선언" 한 줄뿐. ③ 상위는 비유·지도·챕터 6~10개로 학습 가치가 커 보이고, 하위는 챕터 5개로 단순. ④ 좋아요율은 코워크 2.0%, 바이브 1.7%, 코덱스 1.2%, 루프 0.76%, PPT 1.5%로 루프는 도달은 높으나 반응률이 낮음(신개념이라 시청 위주). 길이는 상위가 오히려 더 긺 -> 짧다고 유리하지 않음.

### 신영선의 AI탐구
- 상위: 코덱스 5가지 74.7K(8:12), 이미지 자동화 60K(14:59), 헤르메스 팟캐스트 44K(18:29), 블로그 32.8K(14:57). 하위: 그록봇 18.7K(11:42).
- 차이: ① 상위 = 이미 쓰는 사람이 많은 주류 도구(코덱스·GPT) + "99%가 모르는 5가지, 8분"처럼 압축 약속 + 짧은 길이. ② 중간 = 구체 결과(카드뉴스·배너)와 "100% 자동화" 약속은 있으나 길이가 15분. ③ 하위 = 신제품(그록봇)이고 월 300달러대 요금제 부담 + 본인이 "직장인에게 적합하지 않다"고 말해 시청 동기 약화. ④ 전 편 좋아요율 약 1.0~1.2%로 균일, 댓글은 인터뷰(56)·코덱스(46)·블로그(44)에서 높음 -> 사례형·실전 시연이 댓글 유발. ⑤ 가장 짧은 영상이 가장 높은 조회 -> 이 채널은 길이가 길어질수록(15분+) 조회가 줄어드는 경향.

### 4채널 종합 관찰
- 조회 상위 영상의 공통점은 ① 이미 대중이 쓰는 도구/이슈에 붙고 ② 숫자·범위(5가지, 12개, 10분)로 압축 약속을 하며 ③ 첫 30초에 손해 회피·권위·결과 선공개 중 하나가 분명하다는 점이다. 하위는 신제품·고가 도구·기술 설치 중심이며 훅이 제품 소개로 시작한다.
