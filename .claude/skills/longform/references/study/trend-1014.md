## 2. 상위에서 겹치는 것 — 세 개만

1. **AI 쪽 1등 공식이 한 가지로 몰려 있다**: «퇴근시간 N시간 당겨주는 + [다들 쓰는 도구] + 숨은 기능 10가지 + 무료 프롬프트» — 같은 틀이 상위 7편 중 3편(259만 · 38만 · 18.5만). 길이 19~33분. 훅도 같다: «아직도 ~만 시키고 계세요? 10%도 못 쓰고 계신 겁니다 → 저도 처음엔 그랬어요 → 특히 N번째는 깜짝 놀라실 거예요 → 전공자 아니어도 괜찮아요 → 바로 시작할게요».
2. **자영업 쪽은 지금 «불황·위기 + 왜»가 뜨겁다**: 장사가 역대급으로 안 됨(81.6만) · 무인매장 잔혹사(5일 352만) · 카페 줄폐업 · 자영업 대재앙 · 로봇으로 인건비. 사장님들이 지금 제일 아픈 데가 «매출 급감 + 인건비».
3. **두 쪽 다 «대상 + 손해 + 숫자»**: 직장인·사장님을 부르고, 「10%도 못 쓴다 / 망한다 / 대체된다」로 손해를 찌르고, 숫자(10가지 · 2시간 · 90%)로 약속한다.

## 3. 첫 편 추천 — 위 1번 공식 × 2번 주제

**«장사 안 되는 요즘, 사장님이 AI로 바로 줄일 수 있는 일 10가지 (무료 프롬프트)»** (15~19분)

- 1번(AI 1등 공식: N가지 + 무료 프롬프트 + 퇴근 시간)을 2번(지금 제일 뜨거운 자영업 불황)에 그대로 얹었다. 둘 다 최근 90일 실측 상위.
- 성제관 구조에 맞음: 10가지 각각 «AI가 해 주는 것» → 마지막 한두 개는 «이건 AI가 못 해요, 사람이 봐야 해요»(컨설팅 지점). 빡이사 AI 실험 결(직접 해 보고 안 되는 건 안 된다고).
- 쇼츠: 10가지가 각각 30~60초로 잘린다.
- 다른 후보(데이터 근거 있는 것만): «AI로 인건비 줄인 가게들, 진짜 남았을까»(무인매장 352만 · 조리 로봇 92만 근거 — 실제 사례 자료가 많이 필요) · «AI 시대에 사라지는 가게 90%, 살아남는 1%의 차이»(AI튜터랩 11배 틀 × 자영업 위기).

**겹치는 것 세 개**
1. **훅 = «안전해 보이던 쪽이 먼저 무너진다»는 반직관 + 눈에 보이는 장면.** 프랜차이즈(«실패 확률을 낮추려고 고른 프랜차이즈 점주가 먼저 손을 든다» — 상가 거리, 익숙한 간판인데 문이 닫혀 있다) · 손바닥경제(«철밥통 전문직부터 먼저 짐을 쌌다» — 1929년 사과 파는 은행가).
2. **몸통 = 이유 N개(5~7) → «그럼 뭘 봐야 하나» 질문 3개.** 한 사람 이야기(퇴직 가장의 프랜차이즈 — 매출 3천만 원인데 다 빼면 직장 월급)로 숫자를 끌고 간다.
3. **끝 = «마지막 판단·책임은 사람»**(손바닥경제 21분 무렵) — 성제관 1편 결론(도구 / 결정자)과 같은 자리. 길이는 17~37분, 상위 배수는 21~32분.

→ 2편 설계: «AI를 열심히 쓰는 가게가 먼저 사라질 수도 있다»(반직관 훅) → 사라지는 가게 vs 살아남는 가게 짝 3개 → 마지막 판단은 사람. 길이 15~20분.
