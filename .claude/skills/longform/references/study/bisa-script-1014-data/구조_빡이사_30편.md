## 전개 뼈대

### T1. 화면 따라 하기 세팅 튜토리얼 (긴 영상 13편 · 가장 많음)
1. 결과/숫자/고통 선제시 → 약속 → «끝까지 보세요» → «바로 시작하겠습니다» (0~45초)
2. 진입 경로를 말로 박아 줌: «구글에 들어오셔서 메타 광고 관리자 센터 검색을 하시고요. … 웃는 여성분 페이지»
3. **3분법으로 먼저 틀 세우기**: «캠페인=목적 / 세트=타겟 / 광고=소재 … 너 목적이 뭐야? 누구한테 보여 줄 건데? 뭘 보여 줄 건데?» (거의 모든 세팅 영상에서 반복, 후반에 «뭐라고 했죠?»로 복습)
4. 설정 항목을 화면 순서대로 한 개씩: **금지 항목 → 켤 것 → 숫자 → 이유** 4단 문형. 예) «여러 전환 위치라고 누르지 마시고 무조건 단일 전환 위치로 선택을 하셔야 하고 인스턴트 양식으로 하셔야 합니다.»
5. 이론은 일부러 잘라 냄: «이론 설명은 거의 안 하고», «이론을 설명하면 여러분들 시간만 뺏기니까 저 그대로 따라해 주세요.»
6. 곁가지 규칙을 끼워 넣음: 이름 짓기, 카드사 전화, 한국어 설정, 광고 라이브러리.
7. 소재(레퍼런스 구조 차용 → 챗GPT 이미지) → 문구(15~18자, 3~6줄) → 폼(질문 3개, 완료 화면 전화).
8. «동의하고 개시 버튼 누르시면 끝입니다» → 카드 등록 → 결과 판단 기준(3일, CTR 2%, 20% 증액).
9. 자기 한계/실제 결과 고백 + 수강 CTA(약하게) → «도움이 되셨다면 구독·좋아요» → «다음 영상에서 뵙겠습니다».

### T2. 대담 Q&A (2편 긴 영상 + 짧은 5편)
1. 질문자가 시청자 고통을 한 줄로 던짐(«전화를 안 받는 경우도 너무 많고 허수도 많던데»)
2. 빡이사: «일단 ~해서 그런 경우가 많죠.» 원인 → 처방 숫자
3. 질문자 되짚기(«그럼 ~해야 된다는 말씀이시네요») → «그렇죠.»
4. 정리 한 줄(«정리하면 ~») → 다음 질문
5. 짧은 대담(5~7분) 변형: 민팀장이 도발(«아니 갑자기», «아니 무슨 또 나락을 보내려고 그래요?») → 일화(썰) → 교훈 → «댓글 달아 주시면 구독자한테만 답글» → «꼭 구독 부탁드릴게요. >> 바이.» 또는 «저는 퇴근해 보겠습니다. 바이. >> 바이.»

### T3. 라이브 실험 / 실패 포함 (cfb6, rWfT, m4Qj)
1. 위험하다고 말하면서 시작(«안 되면 마음 아프긴 한데») → 2. 시각·숫자 박제 → 3. 결과 공개(미달도 공개) → 4. «이건 아닌 거 같아요» 결론 → 5. 2탄/다음 예고

### T4. 독백형 원리 설교 (wCPm, hI1q, uZLi, 짧은 영상)
1. 모순/도발 한 줄 → 2. 자기 일화(변태·접을까 만 번) → 3. 비유 연타(골목 운전·여우·전단지·레시피) → 4. 지표 2개/규칙 2~3개로 압축 → 5. 나는 이걸 직접 한다 증거 → 6. 팔지 않는 척 판매(대행 거절·VOD 안 판다) → 7. 구독·좋아요(«구독은 안 눌러 주셔도 되니까 좋아요는 한 번만»)

### 공통 규칙 (T1~T4)
- 한 영상 = 한 가지 행동 목록. «질문 3개까지», «세 개~다섯 개», «3만 원 이상», «3일» 같이 **숫자 한 개로 결론**.
- 같은 규칙을 2~3번 반복하고 스스로 인정: «이거 반복해서 두 번이나 얘기하는데 그만큼 중요한 거니까», «계속 말씀드리지만», «다시 한번 말씀드리지만».
- 팔 때는 «수강생들한테만 알려 드리는 꿀팁»을 **살짝 보여 주고 «여기까지만 풀게요, 혼날 수 있어서»**로 멈춤(wCPm[04:44], 98cE[36:11], 92nU[16:00]).
- 판매 구조: ①무료 풀이로 신뢰 ②«유튜브에 100% 다 풀 수는 없어요, 먹고 살아야 하니까» ③«직접 해 보고 오세요(일단 해 보세요)» ④«월 순수익 1천만 원 미만은 대행 말고 수강» ⑤고정 댓글 링크. 직접 판매 문구가 가장 짧은 영상은 0~2문장, 가장 긴 영상(95jw)이 1문단.

### G. 숫자 표현 방식
- 규칙을 숫자 하나로 못 박는다: «3만 원 이상», «최소 3일», «세 개에서 다섯 개», «20%씩만», «15자에서 18자», «3초», «질문은 세 개까지», «빈도 3 이상이면 끄세요».
- «N만 원» 168회, «N%» 91회, «N초» 64회, «N일» 70회. 범위는 «A에서 B» 로 말한다(«3만 원에서 5만 원», «세 줄에서 여섯 줄»).
- 막연한 수는 «한 + 숫자» 로 어림: «한 3일», «한 2, 3천», «한 100개», «한 달에 보통 3,200개 이상». 퍼센트 단정은 근거를 안 대고 박는다(«이탈율이 6%씩 오른다», «로딩 1초 늦어질 때마다 전환율 7%씩 빠져요»).
- 가격은 천 단위 쉼표 숫자로 읽고(«4,400원짜리», «45,000원») 큰 돈은 «1억·300억·2,900만 원» 식으로 한 번에 박는다.
- 계산을 입으로 보여 줌: «만 원 곱하기 50은 50만 원이잖아요. 그걸 7로 나누면»; 비교 쌍: «가맹비 면제 vs 월세 지원», «210만 원 vs 하루 2만 원», «6만 원 → 4,400원».
- 숫자의 법칙을 직접 가르침: «저 메타 광고 정말 잘합니다 vs 저 메타 광고 18년 했습니다. 그동안 누적 광고비만 300억»[92nU 19:01].

### H. 반말–존댓말 섞는 방식
- 기본은 존댓말(-요/-죠/-ㅂ니다 혼용: «-요/-죠» 구어체 70% 이상). 단정할 때만 «-ㅂ니다/-겁니다»로 올라감(«절대 안 됩니다», «큰일 납니다»).
- 반말로 떨어지는 4가지 자리:
  1. **AI 프롬프트를 소리 내어 읽을 때**: «인테리어 업종 광고랑 홍보 영상 레퍼런스를 좀 찾아줘.» «클로드야 안녕이라는 캠페인이 있잖아. 이 캠페인 이름을 … 변경해 줘.» (48회, 11편)
  2. **시청자·고객의 속마음 대사**: «아 이거 내 얘긴데», «내가 넣은 거 아닌데요», «저 상담 받아보고 싶어요.»
  3. **혼잣말·평가**: «야, 이것도 해 주네요.»[cfb6 13:43] / «아, 이건 아닌 거 같아요.» / «여기가 꿀단지인 것도 알겠어. 근데 왜 안 알려 줄까를»
  4. **대담에서 일화 풀 때**: «썰부터 좀 풀어 줄게요. 내가 일을 하고 있었어. 갑자기 이제 전화가 오는 거예요.»(0423) — 반말+존댓말이 같은 문장 안에서 섞임
- 감탄·웃음 신호: [웃음] 12회/8편, «Ah.» «Yeah.» 같은 자막 잡음이 엔딩에 붙는 경우가 많음(편집/음악 구간).
- 인용 시 호명: «빠기사님은…» 처럼 시청자 목소리를 직접 불러 와 대답(«박기사님 그러면 어 광고 소재는 어떻게 짜야 하나요?»).

## 문장 길이·호흡

- 속도: 약 8.9자/초(공백 포함, 30편 평균). 자막은 0.7초 쉼마다 끊기므로 줄당 평균 36자(≈4초).
- 문장 길이(마침표 기준): 평균 37자, 중앙값 28자, 90분위 75자, 최대 270자. 10자 이하 초단문이 11%(«그죠?», «보이시죠?», «이해되시죠?», «끝입니다.», «엄청 쉽죠?»). 한 호흡 문장이 길어질 때는 «~하시고요 / ~하는데 / ~거든요 / ~해서»로 계속 이어 붙인다 — 클릭 지시가 한 문장으로 이어지는 형태:
