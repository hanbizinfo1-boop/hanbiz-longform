## 3. 기술 함정과 해결 (수치·명령 포함) — 기존 문서에 없는 것 위주

기존과 같음(참고용 한 줄): 프리미어 볼륨 0dB=0.17783, AE 충돌 복구 창 + `run_ae_guarded()`, 도형 짜깁기 금지, 인지할 텀 0.6초, 효과음 자연 길이 2.5초/0.25초 페이드, 5-3 무음 시간 측정.

### 3-1. 애펙(AE)
- **부모 스케일 함정(03 이전 장면의 원칙, 요약 때 재인용)**: 부모가 키프레임으로 scale 50에서 시작하면 자식은 200%로 보임 → 부모 설정 직후 자식에 `scale.setValue([100,100])`. 판(panel)에 부모 걸 때 자식 로컬 x = 컴프 x − 900(패널 앵커 [0,540], 위치 900).
- **복제 레이어 키프레임 순서(16)**: `layer.duplicate()` 후 값을 바로 `setValue` 하면 «키프레임이 있는 속성에 값을 바로 넣음» 오류(JSX 140행). **키프레임을 먼저 지우고(removeKey) 값 설정**.

### 5-1. 시간대·리듬 (모두 요약본 타임스탬프 기준)

### 5-5. 운영 방식 (밤샘·종료·커밋)

5. **통과/반려 신호 해석**: 통과에 새 규칙이 달려 오는 경우(06).
6. **화면 속 글의 근거**: 숫자·글은 말에서 가져와야 한다(예시 숫자는 «예시» 표기). 07의 제목 «인스턴트 먼저, 랜딩은 나중에»는 앞 말의 압축 — 자동화가 이런 압축을 해도 되는지의 기준(앞 N초 이내 말의 요약만 허용 등)이 필요.

### 6-2. 자동화하면 위험한 지점
1. **AE 대화상자 + 무인 렌더**: 충돌 복구 창(밤 3회 정지), Enter 무효, 마우스 클릭 좌표 의존. → 무인 밤 렌더 전 AE를 완전 종료·충돌 복구 상태 정리, 감시 장치에 «스크린샷 → 창 감지 → 클릭» 폴백, 15분 무진행 시 `aerender` 단독 재시도, 실패해도 다음 장면으로 진행하는 큐.
2. **디스크**: 장면마다 `_tmp/ae*`(수백 MB~GB) 생성. 정리 시점·보존 대상(납품본) 명시.
3. **혼동되는 시각 기준**: 자막 시각(구간 찾기) / 단어 시각(움직임) / 사장님 컷 경계(끝점) 세 가지. 컷 경계를 0.001초만 넘어도 이음새가 깨진다. 컷 경계는 prproj에서 읽은 값을 절대 기준으로.
4. **프리미어 볼륨 환산**: 0.17783. 이미 한 번 사고(부호 반전 + 15dB). 자동화에서도 `ZERO_DB` 상수만 사용.
5. **흐림/블러는 클립 효과**: 새 클립으로 교체하면 사라진다. 교체 후 사장님에게 반드시 안내하거나 장면에 굽기.
6. **Codex 결과 위치**: 프롬프트에 복사 경로 미지정 시 저장소로 안 옴. 투명 배경도 보장 안 됨(15). 이미지 안 글 읽힘 안 보장 → 글자는 항상 후처리로 구움.
7. **비교 연출 남발**: 06·07·08 1판이 모두 비교 판이었음 → 사장님이 «너무많으면 안좋아». 서랍에서 고를 때 **직전 N장면에서 쓴 구도 유형은 감점**하는 규칙(원칙 «시그니처 모티프 반복 vs 구도 복제 금지»는 SKILL 4장에 있음)을 기계 규칙으로.
8. **“튕김/바운스” 자동 생성 위험**: AE 기본 이징은 `ez`(양쪽 감속)라서 «버벅거림». 모든 등장은 `eo` 사용. 캐릭터 스쿼시만 예외(애니메이션 표현).
