## 3. 기술 함정과 해결

### 3-A. 프리미어 FCP XML (핵심, 클로드 실수와 연결)
- **XML Basic Motion `center` 를 넣으면 프리미어에서 화면 밖으로 나간다**(09-23 이어하기.md). 10-12 에 `--v2 60 -0.4266,0.337` 같은 center 값을 넣어 만들었다가 사장님이 질문하는 사이 스스로 발견해 **같은 파일명으로 덮어써 재생성**. 현재 옵션: `--v2-scale <비율>` (4K 카메라 50 기본 / 1080p 카메라 100), 위치는 항상 `None` (`<horiz>` 0개 확인). 30% 왼쪽 아래 배치·원형 마스크는 사장님이 PIP 속성 붙여넣기로.
- 1080p 카메라에서 «30%» 를 XML scale 로 쓰려면 60 이 필요했다(화면 비율 환산) — 쓰지 않기로 해서 불필요.
- 기준 문서 «처음부터 왼쪽 아래로 깐다» 와 충돌 → «XML에는 크기만 넣는다» 로 수정. (이 폴더 silence-cut.md 6장 «사람(V2) 배치: 평소 30% 왼쪽 아래» 와 충돌 가능 → **확인 필요**: XML 에는 넣지 않고 사장님이 붙여넣는다는 점이 명시돼 있어야 함. lecture-graphics 180행에는 반영돼 있음.)
- 원형 마스크는 XML로 안 넘어간다 (기존과 같음).
