3. **계획표 먼저 보여 주기** — 새 연출은 바로 만들지 않고 «시각 | 대본 | 화면 | 카메라 | 효과음» 표로 제안하고 승인(«응 진행해» / «오케이 진행해» / «A로 가자»)을 받고 시작한다. 방향이 둘 이상이면 시안 3~5개를 한 장으로 비교.
4. **사실·자료 확인** — 자막에 나온 숫자·고유어가 자료(PDF)에 있는지, **앞 편들에서 이미 쓴 자료·컷인지**를 먼저 본다(분양 시리즈는 «겹치지 않게» 규칙). 근거가 없는 말(예: 한강공원, 어린이집)은 보고에 «PDF에 없는 말»로 표시.
5. **재료 만들기(무료 먼저)** — Codex로 이미지(시작·끝 프레임·카드 사진) → (필요하면) 블렌더 프리비즈 → **유료 영상화(장면당 1건)** 순.

8. **납품** — `완성본\<건>\` 에 ①영상(.mp4 또는 알파 .mov) ②`_효과음\` 낱개 wav ③**배치 XML**(프리미어에서 불러오면 그 시각에 놓임) ④미리보기. **프리미어에 이미 들어간 파일은 잠겨 있으니 새 이름(_v2, _v3)**. 보고 직전 **폴더를 탐색기로 연다**(«폴더를 열어 두었습니다» 거의 매 보고).

### 3-2. 싱크 (본편 무음편집)
- 교차상관으로 소리 오프셋을 재도 **녹화 프로그램의 소리 시계가 느려서**(1시간에 약 4.6초) 소리끼리 맞추면 끝으로 갈수록 어긋난다. **화면 사건(벤츠 이미지 전환 3514초 ↔ 말 «자 나왔죠?» 3516.8초)을 기준**으로 구간별 오프셋 곡선을 만든다. XML 클립 오프셋 범위 **1.24~2.53초**(로그 기준). [기존과 같음: silence-cut.md 7장에 1.28→6.89초 등 같은 사건]
- 클릭 소리와 화면 변화의 **표본 대조는 표본이 적으면 결론이 안 난다** → 프레임 차이량 ↔ 날카로운 소리의 **연속 상관**을 구간(앞·중간·끝) 3곳에서 보는 쪽이 낫다.

### 3-3. 애펙 (AE)
- 파이프라인: Python이 **ASCII JSX**를 쓴다(한글 직접 쓰지 않음) → `AfterFX -r` → `aerender`, 출력 모듈 템플릿 «고품질(알파 포함)» / «고품질».
- 이펙트 속성은 인덱스가 아니라 **match-name**: Radial Blur `'ADBE Radial Blur-0001'`(amount) `-0003`(type), Linear Wipe `'ADBE Linear Wipe-0001/0002/0003'`. 인덱스로 `setValue` 하면 오류.
- 트랙 매트: `setTrackMatte(layer, TrackMatteType.ALPHA)`, 안 되면 구 API 폴백.
- 선형 와이프는 각도 0이 아니면 **아래→위**로 그려질 수 있다(07 카드가 아래부터 그려짐 → angle 0, 06 카드는 «위→아래»로 뒤집음).
- 모션블러로 빠른 오브젝트(기차)가 반투명하게 번져 보이면 **속도를 낮추고 셔터 각 상향**. 줄무늬로 보이면 너무 빠름.
- 빨간 테두리 그리기 = Shape(rect)+Stroke+**Trim Paths**, 깜빡임 = **HOLD(정지) 키**. 프레임 확인은 테두리 부근 크롭.
- 사진 카드가 «한 세트처럼» 보이려면 Codex 프롬프트에 **같은 마감 톤(원목·그레이지·간접조명)** 명시.
- 충돌 복구 창 문제는 10-07 기록 [기존과 같음].

### 3-4. ffmpeg / 영상 처리
- 마지막 프레임 추출: `-sseof` 가 실패하는 경우 → `select` 필터로 마지막 프레임 선택.
- `hstack` 높이 불일치 → 명시적 `scale`.
- 속도 램프: Hermite 시간 맵 + 프레임 블렌딩(03 사례 TA=0.684, SA=1.95, TE=4.5, SE=5.0). **그러나 이 방식으로 AI 클립 속도를 구간마다 바꾸면 «멈춤»으로 보인다**(06 반려) — 짧은 구간 길이를 맞추는 용도로 한정하거나, 사장님이 배속을 걸게 원본을 준다. [AI 클립 속도 변경 금지는 기존과 같음]

- 유료 생성은 항상 사전 고지: «15 credits for 5 seconds. Generating one clip.» → 보고에 누계.
- 사전 확인 요청이 필요한 일: 외부 파일 다운로드(음원), 광고 사용 허락이 불확실한 자료 사용, PDF에 없는 사실 사용, 컷 변경이 생기는 대안.
- 하네스 위에 사용자 질문: «헤르메스 에이전트 플러그인이 지금 엄청 좋다는데 우리 워크플로우에 적용하는게 적합할지 판단해서 알려줘» → «오케이 그럼 넣징낳고…» (도입 안 함). 도구 평가 요청은 판단을 요구하는 질문으로 오고, 사장님은 판단을 수용한다.

## 6. 자동화로 옮길 때의 빈칸

### 6-1. 사람 판단이 꼭 필요했던 지점
1. **연출 선택(시안 고르기)** — 클로드 추천과 사장님 선택이 달랐다(02에서 ③ 추천 → ④ 선택). 선택 기준이 로그에 명시되지 않는다. → 자동 모드에서는 «템플릿 서랍의 기본 1안 + 사장님이 아침에 바꿀 수 있는 대안 1~2안을 같이 렌더»해 두는 게 낫다.
2. **효과음 취향** — 합성음·시네마틱·팔레트·사장님 조합 모두 반려됨(07:25). 사장님이 승인한 소리는 **시안 C(사장님 팔레트 파일 조합)**와 «적당히 괜찮네, 볼륨만»(빡이사 01 효과음) 정도. → 자동 모드 효과음은 **사장님 팔레트(예능 693개 등급표)에서만**, 새 합성·외부 다운로드는 하지 않는다. 소리는 못 들으므로 크기·onset 규칙으로만 보증한다.
3. **번복** — 사장님은 요청을 바꾼다(흰판 «빼자» → «넣고 진행»). 자동 모드에서 **중간 번복을 받을 사람이 없으므로** 모든 대안을 파일 이름으로 보존(_v1/_v2)하고, 사장님이 보시는 최종판은 항상 같은 이름 제자리 덮어쓰기(롱폼 CLAUDE.md 9번)로 하되 **이전 판을 `_이전판/`에 보관**.
4. **사실 확인** — 자료에 없는 말(어린이집, 한강공원), 광고 사용 허락 미확인(배포2안), 단지 비교 숫자의 출처 선택(84A 최저가 vs 표 전체 최저). 사람(클라이언트)이 해결해야 하는 사실. 자동 모드: 근거가 없으면 **연출하지 않고 보류 목록에 올림**.
5. **영상 AI 결과의 합격 판정** — 반실사, 컷 전환, 걸음걸이, 손가락, 건물 모양 일관성은 프레임 시트로 클로드가 걸러도 사장님 눈에서 반려됐다(05 v1, 06 v1·v2). 자동 모드에서 유료 영상화는 **하지 말 것**(밤샘 무인 + 장면당 1건 한도 + 합격 판정자 없음). Codex 이미지 + 애펙 + 실화면 연출만.
6. **«이 장면에 어떤 그림이 맞나» 자체** — 사장님은 구체적 그림(카드 2×2, 메타 로고가 퍼지며 화면 반반)을 스스로 말한다. 자동 모드는 이 «말씀의 해상도»를 갖지 못하므로 `auto-pipeline.md`의 템플릿 서랍이 그 역할을 대신해야 한다. 로그가 보여 주는 사장님 지시 문장의 구조: ①시점(자막 첫마디) ②그림 ③움직임/순서 ④강조 방식 ⑤끝 동작 («다시 사람으로 꽉 채우는 장면으로 돌아오는거까지») — 템플릿 파라미터 후보.

### 6-2. 자동화하면 위험한 지점
- **프리미어 저장본 재독이 선행되지 않으면 모두 어긋난다** — 로고 시각이 13.68 → 12.88, 자막 +0.317초, 사장님 확대 161%. 자동 모드 시작·각 장면 직전에 «원문 저장본 해시/수정시각 확인 → 변했으면 재독» 필수.
- **잠긴 파일** — 프리미어가 열려 있으면 이미 가져간 파일 덮어쓰기 실패. 새 이름 → 이름 규칙이 롱폼 9번(같은 이름 덮어쓰기)과 충돌하므로 **납품 폴더 정책을 건당 확정**해 `기록/작업기록.md`에 박는다.
- **효과음이 «사장님이 안 듣는 한 틀린 채로 간다»** — 07:25 이후 사장님 효과음 불만이 이어졌다. 밤샘 자동에서 효과음 오류는 아침에 대량 수정 요청이 된다. 크기표·onset 정렬·rule_check 외에 **효과음 개수 상한**(최소화)과 **빈 구간 허용**을 둔다(분양4 07:26 결정: «최소한으로만 붙이거나 따로 빼 두어»).
- **비용** — 유료 영상화가 한 번 잘못 나가면 27크레딧. 이날 207크레딧 중 반려·재작업으로 낭비된 것은 05 v1(24), 05 v3 Seedance(22.5, 일부 사용), 06 v1(22.5), 06 v2(18) 등 ≥ 87. 자동 모드 금지 또는 사전 승인 쿠폰제.
- **개인정보** — 홈페이지 썸네일에서 간판·대표번호가 나왔다(빡이사 01). 자동 모드에서 실제 화면 캡처를 카드에 쓸 때는 **OCR 검사 + 폐기**(situation-playbook PB-18).
- **외부 음원 다운로드** — 이날은 사장님 허락 후 Mixkit 사용. 자동 모드에서는 **허락 없이 다운로드하지 않는다**(출처표·라이선스 필요).
- **결과 보고의 «직접 듣지 못함»** — 자동 모드 결과 보고(아침 요약)에 이 문구를 필수 유지.
- **문장 복창 없는 진행** — 이날 오해 사례: «뽑아놓은거 XML로»(범위), «5호선 2호선 버튼 밑에 기차»(그림 vs 실사), «드론소리» 지칭 불명. 자동 모드는 모호할 때 **가장 좁은 해석 + 보류 목록**.
- **번복 가능한 지시를 곧장 지우지 않기** — 흰판 사례처럼 되돌릴 수 있게 `VER`/`CARD_ON` 같은 플래그로 도구를 분기해 둠.

### 6-4. 템플릿 서랍에 추가 후보 (로그에서 반복·통과한 연출 문법)
(기존 `templates/카탈로그.md`에 이미 있는지 확인은 이 학습의 범위 밖 — 아래는 로그가 보여 주는 후보)
- **끝 프레임 정지 + 확대 전진(애펙)** — 06 v4: 마지막 프레임 정지, 100→118.5→122%, 앞 2.2초 등속+뒤 0.8초 이즈아웃. 유료 0, 사장님이 직접 제안·통과.
- **2×2 카드 순차 채움** — 빈 카드 4장 둥둥 → 말할 때마다 1/4 크기로 들어가기 → 평면 위 카드 → 빨간 테두리 Trim Paths → HOLD 깜빡 2회.
- **막대 비교 + 강조 괄호 + 테두리 빛** — 숫자는 자료에 근거, 강조색은 정해진 한 항목에만.
- **HUD 락온 줌** — 괄호·격자·스캔선 → 조준선 이동 → 락온 → 디지털 줌 3단 → HUD 꺼짐(글자 없음, 하늘색·흰색).
- **레이아웃 강조** — 비네트 + 얇은 테두리 + 모서리 괄호 + 격자 → 노란 포커스 박스 «착» 조임 → 한 번 두근.
- **빨려 들어감·지진·별 반짝(배경 효과)** — 줌 1→1.32 + 방사형 흐림 + 감쇠 흔들림 + 별 9개 + 플래시.
- **로고 등장** — 빛줄기 → 로고가 가운데에서 양옆으로 열림(흐림→선명) → 하단 문구 떠오름 → 금빛 스침(좌→우, 글자 안 매트) → 후광, 어두운 로고는 아이보리 판 위에.
- **타입명 배지 강조**(노란, 크게, 톡 + 은은한 빛).
- **메타 로고 → 화면 반반 → 카드 8장 → 반짝 → 사람 복귀**(빡이사 01; 시각·순서는 1-2 참조).
- **사진 카드 세트**(같은 톤 4장·8장) — 프롬프트에 «같은 마감, 글자·로고 없음, 성인만, 사진풍».
- **끝 카드(신청하기 버튼)** — 마지막 프레임 정지 + 3초 확대 + 판 + 로고 + 버튼 두 번 두근 + 빛 고리.

### 6-5. 입력으로 반드시 받아야 하는 것(로그에서 역산)
1. 프리미어 최신 저장본(복사해 읽기): 자막(텍스트·시각), V1 클립 구간, **모션(스케일·위치)**, 효과음 클립과 볼륨(0.1778 환산), 사장님 흐림/전환 유무.
2. 단어 시각(STT 또는 자막).
3. 소재 목록과 **사용 이력**(앞 편/앞 장면에서 쓴 것).
4. 사실 근거 표(숫자·고유어 ↔ 자료 쪽수).
5. 금지 목록(업체명·고객·계정·광고 허락 미확인 자료).
6. 크레딧 한도(자동 모드는 0 권장).
7. 납품 정책(덮어쓰기 vs 새 이름).
