### 3-1. 글꼴·글리프
- **맑은 고딕(malgun.ttf)** PIL 25px 안팎에서 받침(ㅌ 등) 뭉개짐 → «갇». 해결: `C:/Windows/Fonts/NotoSansKR-VF.ttf` weight 500 (`bisa_ab_live.ui_font()`). 확인법: 렌더 결과 mp4에서 **그 글자만 원본 크기로 크롭**(`lsheet.png`) 확인. Pretendard는 `C:/Users/user/AppData/Local/Microsoft/Windows/Fonts/` 에 있는지 `ls | grep -i pretendard` 로 확인함.
- **개구(Gaegu)** 에 `·`(U+00B7) `…` `①` `→` 없음 → 빈칸. **Noto Sans KR** 에 `▾` 없음(19). 맑은 고딕에 `✓` `✕` 없음. 해결: 선으로 그리거나 단어로 대체. 기계 점검기 `glyph_check.py`: `fontTools` cmap으로 `missing(text, font)` / `check()`(SystemExit). 한계: **공용 손글씨 함수 `text_png`에만 연결**, 장면 도구별 자체 글 조각 함수에는 미연결 → 새 도구는 직접 호출해야 함. 시험에서 개구 `·→`와 Noto `▾`를 잡음.
- 폰트 파일 위치: `_tmp/fonts/` 도 존재(20에서 `ls -la "D:/영상제작/_tmp/fonts/"` 확인).

### 3-2. 애프터이펙트·렌더
- **충돌복구 대화상자**: AE가 이전 비정상 종료 뒤 뜨는 창이 `AfterFX -r` 스크립트를 막음. `run_ae_guarded()`: 로그가 없는 동안 **25초마다 Enter**, 최대 20회; 로그에 ok가 나오고 프로젝트가 저장되면 **20초 뒤 강제 종료**. Enter가 가끔 안 들어가면 **마우스 클릭 (1160, 646)** 로 닫음(14·15·16). 스크립트가 끝나도 AE가 안 꺼지면 `taskkill //F //IM AfterFX.exe`, `aerender.exe` 도 같이.

## 6. 자동화로 옮길 때의 빈칸

### 6-1. 사람 판단이 꼭 필요했던 지점
1. **구간·장면 선택**: 원문(SRT)은 사장님이 정함. 자동 파이프라인은 «어느 구간에 장면을 얹을지»를 판단하면 안 됨(CLAUDE.md 11과 일치). 이 세션에서도 모든 장면이 «사장님이 지시한 구간»이었다.
2. **연출 갈래(§ 어떤 기법인지)**: 지시에 이미 갈래가 들어 있었다 — 13 «실제 광고 페이지에 설정하는 듯한», 17 «핸드폰으로 보는 화면», 18 «2D 애니메이션 3인칭», 19 «광고관리자 실제화면 참고해 임의로», 20 «마우스포인트·확대·강조», 21 «직원 입장 2D», 22 «모션그래픽 화려하게 자료 날아다님», 23 «블러 후 댓글 쑥 나와 확대». 자동 모드에선 **지시가 없으므로 상황→갈래 매핑(situation-playbook)** 이 필요하고, 이 세션의 반려 이력이 «갈래를 틀린 것»(08 v1 휴대폰, 11 v1 실사)이었음을 감안해 **갈래 선택은 반려율이 가장 높은 판단**.
3. **손짓·마우스 정합성**(17·20): 프레임을 보고 방향/위치를 판독하는 일은 비전 모델이 필요하고 오판 위험이 크다. 이 세션에서는 0.25초 시트로 클로드가 눈으로 확인.
4. **소리 판단**: 뜻(긍정/부정/중립/조건)과 그림 종류(도장·체크·전화)에 따른 선택은 사람(사장님)이 가장 자주 반려. 이 세션에서도 22 반려.
5. **개인정보·실제 업체 판별**(19 광고 라이브러리 화면, 23 댓글 ID): 사람 판단 → 자동화에선 «업체명이 보이면 재현으로 전환 / 댓글 화면은 블러 필수» 규칙 + 사람 검수.
6. **통과 판정**: 이 세션에서는 «통과» 문구를 말한 건 사장님. 클로드의 프레임 검수는 필요조건일 뿐 충분조건이 아님.

### 6-2. 자동화하면 위험한 지점
- **사람 굽기(V2)**: 같은 실수가 21·23에서 반복됨 → 기본값 `WITH_PERSON=False`, 반반 장면 예외는 명시 플래그로만. (원본 `study/origin-session-1008.md` #21에 «반려→사람은 굽지 않고 V1만 (자동 모드는 굽는다)» 라고 적혀 있는데, 이 세션 요약만으로는 «자동 모드에서 굽는다»는 근거를 찾지 못함 — 이 판단을 하게 된 맥락은 다른 digest 확인 필요.)
- **Codex 산출물 경로**: 폴링 루프가 무한 대기 → 타임아웃 + 경로 이중 확인 필수.
- **패치 적용 확인 없이 렌더**(13): 자동 파이프라인이 코드를 스스로 수정하면 «적용 여부 + 문법 + 글자/레이아웃 검사» 후에만 렌더.
- **AE 충돌복구 창·강제 종료**: 무인 야간에는 `run_ae_guarded` 필수. Enter가 안 들어갈 때 마우스 좌표 클릭(1160,646)은 **화면 해상도/배치 의존** → 다른 PC에서 깨질 수 있음.
- **렌더 부하**: AE 디스크 캐시 44GB, 중간 .mov 13GB/25개. 밤새 수십 장면이면 디스크가 찰 수 있음 → 장면별 정리 + 용량 체크. 보호 장치가 임시 폴더 삭제를 막으므로 AE 캐시는 AE 내부 Purge나 사장님 수동 필요.
- **resume 훅 크기**: 주입량 한도를 넘기면 규칙이 잘림 → 자동 모드에서도 크기 점검.
- **키프레임 순서·텍스트 겹침**: 렌더 후 프레임 검수가 없으면 겹침을 못 봄(13 이름 겹침은 렌더 후에야 발견). 자동 검수 최소 요건: ① 단어 시각마다 프레임 ② 텍스트 크롭 대조(OCR 또는 비전).
- **효과음 규칙 충돌**: 5-3 빈 구간 점검기 vs «요소를 끼우지 않는다». 해결은 «그 시각 말에 맞는 움직임과 소리를 하나 더» — 어떤 말에 어떤 움직임을 추가할지는 판단 필요.
- **pip 위치와 겹침**: 사장님의 V2 PIP는 왼쪽 아래 30%(위치 0.0734, 0.837)이고 반반 장면은 사람이 왼쪽 절반으로 이동. 이 좌표가 건마다 달라질 수 있어 읽기 필수.
- **업체명·계정 노출**: 사장님 캡처(19 광고 라이브러리, 23 댓글 등)에는 실제 업체/ID가 있음 → 자동 모드에서 소재를 쓰기 전 마스킹 필수.
