## 2. 말투 (M-말)

1. **합니다체가 기본**, 동의를 받을 때만 «~죠». 반말·감탄 없음. 문장은 짧게(한 줄 한 숨).
2. **어려운 말은 풀고 나서 이름을 붙인다** — «숫자 61개를 받아 14개를 내놓는 이 계산을 **정책**이라고 부릅니다.» 이름 먼저 던지지 않는다(«이 낯선 단어는 잠시 뒤에 풀어 보겠습니다»로 미루기도).
3. **숫자는 생활 단위로 한 번 더** — «399달러, 우리 돈 55만 원쯤» · «약 100마이크로미터, 종이 한 장 두께쯤».
4. **출처를 말로 댄다** — «개발팀 문서엔 이런 문장이 있습니다.» «논문 초록에 적었습니다.» «공개하지 않았습니다.»(모르는 건 모른다고)
5. **확인된 것과 아닌 것을 가른다** — «보도로만 확인됩니다» · «확정은 아직입니다» · «이번 납품 도면의 숫자는 아닙니다».
6. **비유는 하나, 생활에서** — 폰 자판 자동완성 → 다음 장면 맞추기. 비유한 뒤 «비유입니다»라고 선을 긋기도.
7. **의견은 끝에서만, 이름표를 달고** — «개인적으로는», «제 생각에는».
8. 판매·광고 멘트 없음. 끝 인사는 한 줄.

### 5-2. 4편 대본 규칙 (S1~S8)
- **S1 주제** = 대표님들이 이미 들은 **소식·말 하나**(배달앱 정책 변경 · 수수료 개편 · 최저임금 결정 · 새 AI 기능 출시 · 플랫폼 순위 기준 변경 등) + 그 안의 **«이상한 점»**. 원리로 풀 수 있어야 한다(«왜 ~인데 ~일까»). 성적표·목록형 주제는 피한다(528회 교훈).
- **S2 질문은 30초 안**(M3) · 본론 «먼저 ~부터»는 1분 30초 안.
- **S3 사실은 전부 출처가 있는 것만** — 공정위·서울시·통계청 조사, 플랫폼 공지·약관, 기사. 출처를 말로 댄다(M-말 4). **지어낸 상담 사례 금지**(기존 규칙 그대로 — 모냐구가 믿음을 사는 방식이 바로 이것). 관장님 실제 경험은 사장님이 확인해 주신 것만.
- **S4 원리 단계 3~5개**, 장 제목은 꼬리 질문. «아는 것부터 → 새것 + 생활 비유 하나».
- **S5 다른 시각** 한 칸 필수(«다들 이렇게 봅니다 → 그런데 하나씩 대 보면»).

- **S7 정리**: 처음 질문에 답 + 첫 장면으로 돌아가 한 줄 + 짧은 인사. 다음 편 약속 없음(«다음 소식도 빠르게» 같은 일반 인사는 됨).

- 기존 규칙 유지: 호칭 «대표님» · «수익» · 예시 업종 앞 세 편과 안 겹치게 · AI 티 금지어(bisa-script 4장) · 플랫폼 약관에 걸리는 방법 권하지 않음(8-47).

### 5-3. 화면 규칙 (3편부터)
- 장면은 **실물 층 ↔ 설명 층을 번갈아** 둔다. 실물 층 = 실제 자리(정산서 실물 · 가게 안 · 배달앱 화면을 다시 그린 것 · 조사 보고서 캡처). 설명 층 = 모눈 종이 위 파란 선 그림.
- 원리·계산은 **한 단계씩 쌓는다**(3편: 1만 2천 원 → 정산서 한 줄씩 빠짐 → 천 원).
- 왼쪽 위 이름표 칩 · 큰 숫자 파랑 · 틀린 것 빨강 · 확인 초록.
- 근거는 **원문 카드 + 형광펜 + 출처 줄**(3편: 서울시 조사 문장).
- 끝 정리 = 앞 그림 다시 나란히. «지켜볼 것 세 가지» 빈 칸 카드는 4편부터(3편 대본엔 없음).
