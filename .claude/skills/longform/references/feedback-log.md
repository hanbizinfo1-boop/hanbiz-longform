기록 습관
- 사장님 프로젝트를 다시 읽을 때는 **최신 자동저장본을 사본으로 떠서** `tools/read_lecture_edit.py <사본> <시퀀스이름> <출력.json>` — 콘솔 한글은 `PYTHONIOENCODING=utf-8`. 같은 json 의 `track=="C1"` `text` 가 자막. 사본 json 을 `python -I` 로 읽으면 PYTHONIOENCODING 이 무시돼 한글이 깨져 보인다(파일은 정상 UTF-8).
- 사장님이 «N분 이후 자르기 조정» 하셨다고 하면 그 뒤 장면은 **구간을 다시 잡는다**(10-08 22 «36분 이후로 프리미어 자르기 조정 있어서 SRT 타임라인 재파악해서 진행»).
- 효과음 클립 볼륨을 만지신 저장본을 읽으면 파일별 크기표(`sfx.md` 3-3)에 더한다. 환산 0dB = 0.17783.
- 한 건의 «경로 지도»(프리미어 프로젝트·원본 영상·녹화본·납품 폴더)를 `기록/작업기록.md` 맨 위 가까이에 둔다. 영상 원본은 저장소 밖 — 경로만.
- 시작/끝이 사장님 클립 가운데면 보고에 «잘라서 바꿔 끼우기», 사장님 V2 가 그 구간 전체 화면(50%)이면 «PIP 로 바꾸셔야 보인다».
