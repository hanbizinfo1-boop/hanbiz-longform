## 1. 화면은 네 가지 장면으로 돈다 (편집문법 0장)

| 장면 | 화면 | 그 위에 얹는 것 | 주로 쓴 강 |

| **B. 풀샷** | 강사 + 뒤 전자칠판 | 칠판 옆 빈 곳에 글자 목록 (흰 제목 + 노랑 강조) | 1·2·3·8강 |

## 2. 강조 그래픽 문구 유형 6가지 (설계-그래픽자동배치 — 설계안, 구현 전)

2강 실제 문구 32개에서 역산. **기계는 제안하고 사람이 확정한다**(강조는 «무엇이 중요한가» 판단).

| 유형 | 형태 | 색 | 예 |
|---|---|---|---|
| ① 용어 제시 | 단독, **아주 크게** | 흰 | 비유동자산 · 당기 순이익 · 부채 비율 · 정책자금 |
| ② 번호 리스트 | `1.` `2.` `3.` 2~3줄 | 흰 | 1. 소진공 / 2. 중진공 |
| ③ 부연 | **`→` 로 시작**, 항목 바로 아래, 작게 | **골드** | → 대출 기간 1년 이하 |
| ④ 정의·조건 | `=` 기호 | 골드/흰 | 통상 상환기간 = 5년 |
| ⑤ 수식 | `÷ × +` 기호 | 흰 | 부채총계 ÷ 자본총계 x 100 |
| ⑥ 질문 | **`?` 로 끝남** | 골드 | 단기 차입금? · 건물이 임대인가? |

- **가장 중요한 구조 — 쌓아 올린다.** 화면을 한 번에 완성하지 않고 하나씩 추가하며 누적(405.7s `1. 단기 차입금` → 408.9s `+ → 대출 기간 1년 이하` → 411.5s `+ 2. 장기 차입금` …). «동시 표시 최대 5개»의 정체 = 한 화면이 5단계로 완성. 누적 중인 화면에는 새 «용어 제시»를 넣지 않는다(덮어쓰기).
- 검출 신호: 처음 나오는 용어(명사구) → ① / `첫 번째·두 번째·N가지·하나는` → ②(항목마다 따로 등장) / 항목 직후 설명절(`~는 거예요`, `~라는 뜻입니다`) → ③ / 숫자+단위 → ④ / `나누기·곱하기·빼기` → ⑤ / `~인가요? ~일까요?` 또는 대비 → ⑥. 안 하는 것: 접속사·추임새만 있는 구간, 영상 맨 앞 3초·맨 뒤 3초.
- 길이: 실측 중앙값 4.69초(최소 0.22 / 최대 27.9, 3~6초가 가장 두껍다). 수치(highlight) 기본 4.7초(어절 발화 끝 + 3초), 열거(list)는 마지막 항목 발화 끝 + 2초(최소 6초). 리스트는 «항목 1줄» 템플릿을 여러 번 쓰는 구조가 낫다.
- 밀도: 실측은 뒤로 갈수록 성기다(0~5분 6.8개/분 → 10분~ 2.2개/분)지만 시간이 부족해서였다(사장님 확인) → 목표는 초반 밀도 **6.8개/분**을 끝까지. 효과음 초반 6.2회/분. 점수 = 유형 강도(리스트 3 / 용어 3 / 부연 2 / 수치 2 / 질문 2 / 수식 1) + 발화 강조. 단, 이제 자료 자리는 사장님이 지정하므로 «후보 찾기»로만 쓴다.
- 효과음 배정(그래픽 길이): 2초 미만 `2. 띠딩2` · 2~10초 `도장` · 10초 이상 `휙２`. 볼펜소리는 사람 몫.
