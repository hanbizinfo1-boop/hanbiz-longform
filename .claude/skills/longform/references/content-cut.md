# 내용 컷 — 사장님이 더듬기·다시 말함을 자르는 기준 (빡이사 이사님 강의 전용)

> 원본 `D:\영상제작\빡이사DB\내용컷-규칙.md`(10-12)를 옮겼다. 자동 연출 모드는 «사장님 컷 완료본(원문)»을 받으므로 이 단계를 하지 않는다 — 사장님이 «내용 컷도 해 달라»고 하실 때의 근거다.
> 사장님 10-12: «내가 더듬거나 내용 이상하면 자르거나 했던 부분, 내 기록 학습 데이터 기반으로 너에게 시키면 할 수 있겠어?» · 범위 «**창근님 시리즈는 빡이사가 아니야. 빡이사 것만 참고해서** 진행해야 해.» · 방식 «**이번 편집을 일단 내가 하고, 레퍼런스 여러 개를 네가 대조해 보는 형식**으로 학습시켜 봐야 할 것 같아».

## 0. 지금 결론

- **자르지 않는다. 미리 후보도 만들지 않는다.** 사장님이 편집을 끝낸 편을 정답 레퍼런스로 하나씩 쌓는다(사장님 편집 전에 후보를 붙이면 정답지가 오염된다).
- 후보를 드리게 되더라도 **마커로만**, 그리고 **정밀(맞은 비율)을 재현(잡은 비율)보다 먼저** 본다 — 필요한 말이 잘리면 사장님이 찾기가 더 어렵다.
- 1차 시험은 **재현 36% · 정밀 37%** → «지금 수준으로는 쓸 수 없다».

## 1. 사장님이 자르신 것 — 빡이사DB 본편(원본 64.7분, 내용 컷 231곳 482초) 학습 구간 126줄

|---|---|---|---|
| A | **다시 찍은 앞 판** | 같은 설명을 조금 뒤(몇 초~1분 넘게)에 다시 깔끔하게 했으면 **앞 판을 통째로**. 문단 하나가 통째로 날아가기도 한다 | 예산 설명 1000~1057초 → 1058초부터 다시 · 상세 타겟팅 꿀팁 1497~1561초 → 1576초부터 다시 · 1135 → 1146 · 603 → 611 |
| B | **문장 중간에 다시 시작** | 말하다 멈추고 같은 낱말로 다시 시작하면 앞 조각 | «잘 할 수 있는» → «우리가 잘 하려면» · «실력 쌓고 넘어가시는 걸 말씀을 드리…» → «실력 쌓고 넘어가시고» |

| E | **끊긴 조각** | 한두 낱말(«말고» «나는» «자» «이렇게») — **바로 뒤에 같은 말로 다시 시작할 때만** | |
| F | **곁가지·내부 이야기** | 수강생에게 필요 없는 내부 사정, 같은 예를 한 번 더 | 내부 담당자 단가 이야기 · «스킨케어 누르니까 내추럴 스킨케어도 나오네요» |

**자르지 않는 것**
- 같은 낱말이 나와도 **설명이 앞으로 나아가면** 둔다(«예를 들어서 보험이다 / 광고다»처럼 예를 늘어놓는 것).
- **가르치는 내용 자체인 문구 읽기는 남긴다** — 광고 문구(«최장 84개월로 더 여유롭게…» 27줄), 양식 완료 문구(«상담이 급하시거나… 1분 만에 상담사와» 13줄) 모두 살리셨다. D 는 «준비 작업 중»만.
- «그래서» «그러면» «이거» «여기» 같은 말 이음은 대부분 두셨다.
- 짧은 화면 조작 혼잣말(«이리와»)도 남기신 곳이 있다 → 애매하면 후보로만.

## 2. 1차 시험 (원본 10-12)

- 방법: 앞 0~1940초(학습)에서 규칙을 뽑고, 뒤 1940초~(537줄, 사장님 내용 컷 112곳 214초)는 답을 가리고 맞혀 채점.
- 결과: 재현 112곳 중 40곳 = **36%**(초 29%) · 정밀 후보 166초 중 **37%** · 사장님이 살린 줄을 후보로 찍은 것 77줄.
- 틀린 이유: ① G(홍보·마무리)가 학습 구간에 없었다 — **시간 앞뒤로 나눠 배우면 끝부분 종류가 시험에만 몰린다** ② D·E 를 너무 넓게 봤다 ③ 판정을 실행 에이전트에 맡겼는데 이유 칸이 «자동판정»뿐이라 줄마다 읽었는지 알 수 없다 → **다음엔 설계자가 직접 판정하거나 줄마다 이유를 받는다.**
- 고친 규칙을 같은 시험 구간으로 다시 재면 답을 본 셈이라 숫자가 부풀려진다 → 재지 않았다.
