### B 경로 원칙 (사장님 10-06)

> «클로드 디자인을 쓸 때는 도형을 조합해서 형상을 표현하는 방식보다는, 필요한 이미지들을 실제 로고나 이미지를 크롤링하거나 GPT 이미지로 만든 것을
> 클로드 디자인에 적용시켜서 디자인으로 필요한 작업을 한 뒤, 추가 작업이 필요하면 애펙으로 넘기기, 없으면 클로드 디자인에서 마무리»

1. **그림은 «진짜 이미지»로** — 휴대폰·로고·사람·제품·화면을 사각형·원·선 조합으로 흉내 내지 않는다(03 휴대폰 모형처럼 PIL 로 그린 것 = 이제 하지 않는 방식).
   - **실제 로고·이미지 받기**: 공식 사이트·브랜드 자료실·위키미디어에서 받는다. 받은 파일·주소·받은 날을 `소재/이미지-출처.md`에 한 줄씩. 403·봇 차단은 우회하지 않는다.
   - **고객 업체명·대표번호·계정 정보가 보이는 실자료는 쓰지 않는다**(업체명 규칙) — 그 자리는 Codex 연출 이미지.
   - **Codex(GPT) 이미지**: 실물이 없거나 쓸 수 없는 것(연출 사진, 휴대폰 손에 든 장면, 배경). 사진풍(`AI영상-주의사항.md`), 무료 한도 안에서.
   - 녹화본 실화면도 이미지다 — 필요한 부분만 잘라(계정 ID·탭·북마크 빼고) 올린다.
2. **캔버스에서 디자인** — 받은/만든 이미지를 캔버스에 자산으로 올리고(로컬 원본 경로는 `자산.json`), 배치·글·색·강조는 캔버스에서 한다. 도형은 카드 바탕·구분선·강조 밑줄 같은 «디자인 요소»에만.
3. **갈림길**
   - **움직임이 필요하다**(단어 시각에 맞춘 등장·반반 열림·반짝·게이지·화면 넘김) → `design_layers.py` 로 레이어를 떼어 애펙으로(아래 순서 4~6).
   - **움직임이 필요 없다**(한 장 띄우는 자료·표·정리 카드) → **캔버스에서 마무리**. `design_layers.py` 의 `_all.png`(또는 캔버스 내보내기)를 납품하고, 프리미어에선 이미지 한 장으로 얹는다(효과음은 등장 프레임에 하나).

### B 경로 순서
1. **캔버스 만들기** — Artifact `quickstart`(intent design) → Design 타입으로 새 캔버스(제목 = 장면 이름, 예 «빡이사DB 04 …»). 비공개로 생긴다. 공유는 사장님이 정하실 때만.
2. **아트보드 = 장면의 «다 나온 모습» 한 장**(1920×1080 고정, `$preview` 같게). 반반 장면이면 오른쪽 판(x 960~1920)만 채우고 왼쪽은 비운다.
   - 움직일 덩어리마다 `data-layer="이름"`(영문·숫자·_). 카드 안 글을 따로 움직이려면 안에 또 `data-layer`.
   - `<sc-for>`·`<sc-if>`·`<dc-import>` 는 쓰지 않는다(정적 마크업). 사진·로고는 캔버스에 자산으로 올리고 로컬 원본 경로를 `자산.json`에 적어 둔다.
   - 업체명·계정 ID·고객 정보 금지(업체명 규칙). 화면 글은 말을 받치는 개념어(한눈에 4), 숫자·고유 표현은 말에 근거.
3. **확인** — 캔버스 링크를 드리고 사장님(·클라이언트) 댓글·수정을 받는다. 반려는 4장 표에, 통과는 2장 표에.
4. **레이어 떼기** — 아트보드 원본을 `Artifact read`(path `project/<이름>.dc.html`)로 받아
   `python tools/design_layers.py <받은.dc.html> _tmp/<건>/dsN [--자산 자산.json]` → `_all.png`(완성) · `_base.png`(바탕) · 레이어별 PNG(화면 전체 크기 제자리, 투명) · `layers.json`(상자).
   `_all.png` 를 캔버스와 눈으로 맞대 본다(글꼴·자산이 빠지면 여기서 드러난다).
5. **애펙** — 장면 도구에서 `design_layers.ae_lines(폴더, AE.js)` 로 바탕·레이어를 깔면 기준점이 레이어 가운데로 잡힌다. 그 변수에 `keys()` 로 단어 시각에 맞춘 등장·강조·퇴장만 건다(반반이면 판에 `parent`).
6. 효과음·`rule_check`·미리보기·납품 3종·피드백 기록은 1장 순서 그대로.

**함정(시험에서 확인)**: 크롬 `--screenshot` 은 절대경로만 쓴다(상대경로면 조용히 안 떨어짐). 투명은 `--default-background-color=00000000` + `html,body{background:transparent}`. 레이어 안 레이어는 부모 PNG 에서 빠진다(따로 움직이라고).

## 1. 순서

1. **앞뒤 맥락**(한눈에 1) — 앞 30초·뒤 15초 자막과 사장님 편집(확대·컷·**V2 사람 크기**)을 읽고 `기록/작업기록.md` 해당 장면에 «앞/뒤 맥락» 줄. 사장님 프로젝트는 **가장 최근 자동저장본**을 `tools/read_lecture_edit.py <prproj> <시퀀스이름> <out.json>` 로 읽는다(자막 C1 · V1 녹화 · V2 사람 · 효과 값). 사장님이 «N분 이후 자르기 조정»을 말하시면 그 뒤 장면은 **구간을 다시 잡는다**(10-08).
2. **구간 확정** — 자막에서 시작·끝을 찾고, 가능하면 **컷 경계**에 맞춘다(클립 가운데면 보고에 «잘라서 바꿔 끼우기»).
3. **단어 시각** — 사장님 컷 조각대로 사람 소리(싱크 영상)를 이어 붙여 faster-whisper 단어 단위(CPU int8 medium). 받아쓰기 오인식은 기록에 같이(«세워라 네워라고» = «세월아 네월아»). 장면의 모든 움직임은 **그 말이 나오는 단어 시각**에.
4. **화면 확인** — 녹화·사람 프레임을 0.25~0.5초 간격으로 뽑아 마우스 위치·손짓·스크롤 시각을 잰다(17 손짓 방향 · 20 스크롤 2136.6).
5. **구도 고르기** — 0장 갈래 표에서 «그 말이 실제로 일어나는 자리». 사장님 지시 원문을 기록에.
6. **시안**(사장님이 «시안 추천» 하실 때만 3안 ASCII) — 방향이 정해지면 묻지 않고 만든다.
7. **그림** — Codex(한 세션에 몰아서, 투명 배경·같은 인물은 앞 그림을 `view_image` 로 물림) · 위키미디어(표준 썸네일 크기, 출처 기록) · 녹화 실화면 크롭. Codex 가 샌드박스 때문에 `소재/` 복사를 못 하면 `_tmp` 에 떨어진다 — 경로를 확인해 옮긴다.
8. **조각 → 정지 스토리보드** — PIL 조각을 만들고 **렌더 전에 «다 나온 모습» 정지 화면을 합성해 눈으로 본다**(겹침·글자 깨짐·주소창 노출을 여기서 잡는다. 13·17·19·20·22 에서 매번 걸림). 겹침 자동 검사(`check_layout`)는 렌더 전에 멈춘다.
9. **애펙** — JSX(ASCII) → `AfterFX -r`(감시 `run_ae_guarded`) → `aerender` → ffmpeg. 등장은 `eo`(빠르게 들어와 감속), UI 는 튕김 없음.
10. **효과음** — 3장. 등급표에서 고르되 **뜻·그림에 맞는지** 먼저, 이름으로 고정, `rule_check.check_sfx` 통과해야 섞는다. 빈 구간에 걸리면 **그 시각 말에 맞는 움직임**을 찾아 붙인다(빈 소리 끼워 넣기 금지).
11. **확인** — 렌더 뒤 단어 시각마다 프레임을 모아 보고 ebur128 트루피크. 소리를 귀로 못 들었으면 «못 들었다».

## 3. 효과음 — 이 장면들에서 정한 방법

- **크기** → ★ 먼저 `sfx.md` 3장 «파일별 크기» 표(사장님 10-07 실측, `FILE_DB` 자동 적용, 표에 없는 파일은 `FILE_DB_DEFAULT`(+5dB) · 반짝 −1dB). 그다음 같은 장의 기본값 줄(사장님 최종값). 처음 «+3dB» 지시를 1dB 넘게 잡았다가 사장님이 내리신 이력이 그 줄에 있다. 펜 소리는 쓰는 동안만. 장면 도구(`bisa_*.py`)의 `SND_FIX` 크기 값은 만들 당시 값이니 새 도구는 기준 줄을 따른다.
- **고르기**: 등급표(`tools/data/예능효과음-등급.json`, 요약 `sfx.md` 4·13장) A★ → A → B. 단, 등급은 소리 «결»만 보고 뜻은 모른다(밑줄에 «잔 부딪힘», 칩에 «카메라 셔터»가 1순위로 뽑힌 적 있다). 그래서 **역할마다 파일 이름으로 고정**한다(`SND_FIX`).
- **사장님 소리와 새 소리를 섞는다**(10-02 «가지고 있는 것에서만 하다 보니 아쉽다»).
- **같은 소리 반복**: 바로 연달아 같은 파일은 금지. 번갈아 쓰기는 3초 간격 사슬 안에서 같은 파일 3번까지(점검기 5-2b, «최대 3번까지는 번갈아»). 카드·칩처럼 연타 자리는 결이 비슷한 다른 파일을 돌린다.
- **게이지·밑줄처럼 차오르는 그림엔 차오르는 소리를 꼭 붙인다**(10-02 «게이지는 왜 뺐어»).
- **같은 소리도 자리가 다르면 별로일 수 있다**. 01에서 통과한 블록소리·キラッ·高速移動·두꺼운 바람이 02 1판에서는 «별로»였다. 그래서 반려는 소리 전체가 아니라 `장면반려`로 적는다.

## 5. 함정

- **프리미어 볼륨 저장값: 0dB = 0.17783**(+15dB 여유). dB = 20·log10(v ÷ 0.17783). 1.0 을 0dB 로 보면 «올리신 걸 내리셨다»고 거꾸로 읽는다(10-07 반려). 환산은 `tools/lecture_edit_profile.py` `ZERO_DB`.
- **위치(공간 속성)에 `eo` 를 걸면 «setTemporalEaseAtKey 배열 요소 1개» 오류** — 공간 속성은 ease 가 1개다. `var n=p.isSpatial?1:(p.value.length||1)`(06 도구).
- **애펙이 «충돌 복구 옵션» 창을 띄우면 `AfterFX -r` 스크립트가 안 돌고 멈춘다**(10-07 밤 14·15, 15분 타임아웃). 앞 실행이 비정상으로 끝나면 생긴다. `tasklist` 에 AfterFX 가 떠 있는데 `log.txt` 가 안 생기면 이 창 — 애펙 창을 앞으로 가져와 Enter(«계속»). 스크립트가 «ok» 를 썼는데 AfterFX 가 안 닫히면 aerender 만 따로 돌려 이어 간다. → **자동화**: `tools/bisa_web_vs_instant.run_ae_guarded()`(이 틀을 쓰는 05~16 도구 공용) — 20초 로그 없으면 Enter, 끝났는데 20초 안 닫히면 강제 종료(10-07 밤).
- **애펙 부모 묶기**: 부모가 키프레임으로 50%에서 시작하면, 자식을 묶는 순간 자식이 200%로 보정된다. 묶은 직후 `scale.setValue([100,100])`, 위치는 그 뒤에 부모 좌표로 건다.
- **판에 묶은 레이어 좌표** = 화면 x − 판 기준점 x(900). y는 그대로.
- **손글씨 글꼴(개구)에는 «·»«…»«①»«→»가 없다** → 빈칸으로 찍힌다. 쉼표·«등»·«1.»·말(«그다음»)로 쓴다. Pretendard에도 «①»이 없다. 맑은 고딕엔 «✓»«✕»가 없다(선으로 그린다).
- **맑은 고딕(malgun.ttf)은 PIL 25px 안팎에서 받침을 뭉개 그린다**(«같»이 «갇-»처럼, 10-08 13 «또 깨졌어»). 녹화 화면 UI 글자를 바꿔 쓸 땐 `C:/Windows/Fonts/NotoSansKR-VF.ttf`(굵기 500) — `bisa_ab_live.ui_font`. 렌더 뒤 그 글자를 원본 크기로 잘라 확인한다.
- **효과음 낱개 wav 이름이 판마다 바뀌면** 예전 파일이 폴더에 남는다(지우지 않는다). XML은 새 이름만 가리킨다.
- 녹화본 실화면을 쓸 때는 주소창(계정 ID)·탭·북마크(«고객사 디비리스트» 등)를 잘라 낸다.
- **글리프 없음은 미리 막는다** — 개구·맑은 고딕·Pretendard 에 없는 글자(«·»«→»«①»«✓»«✕»«▶»«▾»)가 들어가면 빈칸·네모로 찍힌다(20 개구 «·»«→», 19 Noto «▾» — 이미 알던 함정을 또 밟음). **새 글 조각은 `tools/glyph_check.py` 의 `check(글, 글꼴)`로 확인**(없는 글자가 있으면 멈춤). 기호는 선·도형으로 그린다.
- **카메라를 녹화 화면 위에서 옮기면 주소창·북마크가 드러난다**(13) — 카메라 위치를 «녹화 기본 틀 밖이 안 보이는 범위»로 묶는다(`bisa_ab_live.cam_at`).
- **녹화 화면이 장면 중간에 스크롤되면** 강조 위치가 어긋난다 — 기준 화소(초록 버튼 등)의 y 를 0.2초 간격으로 재서 스크롤 시각을 찾고, 그 전후로 나눈다(20: 2136.6 −125px).
- **키프레임은 시간 순서대로** — 같은 레이어에 «나중 시각 키 → 앞선 시각 키» 순으로 넣으면 의도와 반대로 남는다(13 2판 복제 줄에 A·B 이름이 겹침). 바꿔 끼우기(hold)는 «t−0.001 → t» 짝으로.
- **흐린 그림자의 아주 옅은 꼬리**가 카드 둘레에 사각 테두리처럼 비친다(19) — 그림자 알파 8 미만은 0 으로.
- **Codex 그림 안의 손가락·모니터** — 손가락이 휴대폰 화면 가장자리를 덮으면 그 안 글이 잘린다(17: 화면 왼쪽 여백 50). 모니터는 색으로 자동 검출하면 같은 색 셔츠를 잡는다(21) — 그림 비율로 잡는다.
- **위키미디어 이미지**: 썸네일은 표준 크기(250·500px 등)만 받아 준다 — 임의 크기는 오류 문서가 내려온다. API `action=query&prop=imageinfo&iiurlwidth=500` 로 주소를 얻는다.
- **짧은 클릭 소리 과증폭**: 크기를 50ms RMS로 맞추면 10ms짜리 클릭은 작게 잡혀 수십 배로 키워지고, wav에서 0dB로 잘린다(03 «15. 마우스클릭»). `bisa_meta_sfx.prep`에 피크 −6dBFS 상한을 두었다. 미리보기 합본은 섞은 뒤 피크 0.8로 낮추고 리미터(같은 날 +1.3dB 트루피크).
