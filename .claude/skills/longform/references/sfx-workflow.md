# 효과음 워크플로우 — 장면에 소리 까는 순서 · 폴더 주소 · 뜻별 단골

효과음을 깔 때 **이 문서 하나로 시작한다.** 원칙과 근거(왜 이 크기인지, 사장님 말씀 원문)는 `sfx.md`에 있다. 이 문서는 «어디서 꺼내 어떻게 까는지»만 다룬다.
바탕은 빡이사DB 후킹 01~23(2026-10-02~10-08)에서 사장님이 통과·반려하신 실사용 이력이다.

---

## 0. 한눈에 — 10줄

1. **소리는 그림에 붙는다.** 컷에 붙이지 않는다. 그림이 뜨는 프레임(단어 시각)에 소리 시작(onset)을 맞추고, 휙 계열은 소리 꼭대기(peak)를 움직임 꼭대기에 맞춘다.
2. 고르는 순서는 **① 뜻(긍정/부정/중립) → ② 그림(도장·전화·타자·펜…) → ③ 3장 단골 → ④ 등급표 A★→A→B**.
3. **조건·기준 글에는 축하음을 금지한다.** 예: «월 천만 원 미만». **도장 그림에는 반드시 `도장.mp3`를 쓴다**(10-08 반려).
4. 크기는 **파일별 표**를 따른다(`bisa_meta_sfx.FILE_DB`, 표에 없으면 **+5dB**). 프리미어 볼륨 0dB은 저장값 0.17783이다.
5. **자연 길이**로 둔다. 잦아드는 곳까지, 최대 2.5초다. 뚝 자르지 않는다(10-07 «또 짧게 끊기고»). 펜·마커처럼 동작 길이에 맞춰야 하는 소리만 음수 길이로 딱 자른다.
6. **같은 파일을 바로 연달아 쓰지 않는다.** 단계 알약은 pep1·pep2, 큰 글은 衝撃音1·2·3, 클릭은 두 파일을 **번갈아** 쓴다.
7. **소리 없는 시간은 2.5초를 넘기지 않는다.** 걸리면 **그 시각 말에 맞는 움직임**을 찾아 붙인다(소리 꼬리가 빈칸을 메운다). 빈칸을 메우려고 요소·소리를 끼워 넣지 않는다(10-07 «급해서 정신없다»).
8. `rule_check.check_sfx`(5-2 연속 · 5-2b 짧은 주기 · 5-3 빈 구간)가 ERROR면 렌더가 멈춘다. 고치고 다시 돌린다.
9. 납품은 **낱개 wav + `_효과음.xml` + `_미리보기.mp4`**다. 미리보기 트루피크는 −1.5dBFS 이하다. 소리를 직접 못 들었으면 «못 들었다»고 보고한다.
10. 사장님 말씀은 **원문 그대로** `sfx.md` 11장과 `tools/data/예능효과음-실사용.json`(통과·반려·장면반려)에 적는다.

## 2. 찾는 도구 — `tools/sfx_find.py`

```
python tools/sfx_find.py --dirs            # 폴더 지도(있는지·파일 수) — 새 PC·새 세션 첫 확인
python tools/sfx_find.py --roles           # 3장 뜻별 단골 표
python tools/sfx_find.py --role stamp      # 단골 하나의 실제 위치
python tools/sfx_find.py 도장               # 이름 일부로 모든 폴더 검색
python tools/sfx_find.py --cat 05 -n 10    # 등급표 분류 05 상위 10개(A★→A→B)
python tools/sfx_find.py 휙 --play         # 첫 결과를 기본 플레이어로 열어 들어 본다
```

한 줄 형식은 `[폴더] 등급 구울dB 통과/반려 분류 경로`다. 구울 dB는 `FILE_DB` 값이고, 표에 없으면 +5다.
장면 도구 안에서는 `bisa_toc_cards.by_name("파일이름")`이 등급표에서 먼저 찾고, 없으면 `SFX_ROOTS`를 순서대로 뒤진다.

## 4. 작업 순서 — 장면 하나

| 단계 | 할 일 | 산출 |
|---|---|---|
| **S1 박자표** | 장면 도구의 그림 움직임 시각(단어 시각표에서 온 것)을 그대로 소리 자리로 쓴다. 그림이 없는 곳에 소리만 넣지 않는다 | `EVENTS = [(시각, 이름표), …]` |
| **S2 뜻 매기기** | 자리마다 긍정/부정/중립/그림을 적는다. 말이 조건·기준·경고면 축하음은 후보에서 뺀다 | 기록 «효과음» 칸 |
| **S3 고르기** | 3장 단골 → 없으면 `sfx_find.py --cat` 등급표 A★ → 그래도 없으면 `사장님`·`자주쓰는` 폴더를 이름으로 찾기 → `다운`·`오픈소스`는 들어 보고 | `SND_FIX = {이름표: (파일, 길이, dB, 맞춤)}` |
| **S4 반복 피하기** | 같은 이름표가 붙어 있으면 번갈아 쓴다(1·2·3). 3초 안에 같은 파일은 3번까지다 | — |
| **S5 빈 곳** | 소리 없는 구간이 2.5초를 넘으면 먼저 소리 꼬리(자연 길이)로 메워지는지 본다. 안 되면 **그 시각 말에 실제로 있는 움직임**(말한 낱말의 밑줄·확대·카드 퇴장)을 찾아 그림과 소리를 함께 붙인다. 빈칸 메우기용 요소·소리는 끼워 넣지 않는다. 새 요소는 0.6초 혼자 보이게 한다 | 그림 + 소리 한 쌍 |
| **S6 렌더** | `python tools/<장면도구>.py --소리만`으로 그림 렌더 없이 소리만 다시 깐다. 그림까지 바뀌었으면 인자 없이 돌린다 | 아래 «납품» |
| **S7 점검** | 콘솔에 찍힌 `시각 이름표 [등급] 파일 dB` 줄과 `rule_check` 결과를 본다. 미리보기 트루피크는 `ffmpeg -i <미리보기> -af ebur128=peak=true -f null -`로 확인한다 | 보고에 줄 붙임 |
| **S8 기록** | 사장님 피드백 원문을 `sfx.md` 11장과 `실사용.json`에 적는다. 크기를 프리미어에서 고치셨으면 저장본에서 재서 `FILE_DB`에 반영한다(3-1장 읽는 법) | — |

**납품되는 것**(같은 이름으로 제자리 덮어쓰기)
- `납품/<장면>_효과음.xml` — 프리미어 가져오기용. 장면 mp4는 V1, 효과음은 A2 이후 트랙에 시각대로 들어간다.
- `_tmp/효과음NN/01_<이름표>.wav …` — xml이 가리키는 낱개 소리. **지우지 않는다**(프리미어가 이 파일을 물고 있다).
- `_tmp/효과음NN/00_효과음만_합본_<시작>~.wav` — 소리만 한 줄.
- `납품/<장면>_미리보기.mp4` — 장면과 사람 PIP, 목소리 +7dB와 효과음을 섞은 확인용. 리미터는 −1.5dBFS다.

## 5. 크기 — 짧게 (자세한 것은 `sfx.md` 3장)

- 구울 값은 «목소리 원음 대비 dB»다. 사장님 타임라인 목소리(A1)가 +7dB라서 **들리는 크기 = 구울 값 − 7**이다.
- `FILE_DB`에 있는 파일은 그 값을 쓴다. 표에 없는 파일은 **+5**(들리는 크기 −2dB)다.
- 짧은 클릭은 50ms RMS가 작게 잡혀 과증폭된다. 그래서 `prep`이 피크를 −6dBFS로 묶는다. 이 상한을 끄지 않는다.
- 프리미어 저장값을 읽을 때는 **0dB = 0.17783**이다. dB = 20·log10(v / 0.17783).

## 6. 새 소리를 들여올 때

1. 받은 파일은 `다운`처럼 **이 폴더 밖 원래 자리**에 둔다. 이 저장소에는 음원을 넣지 않는다(`.gitignore`가 막는다).
2. 출처·라이선스를 `sfx.md` 10장 표에 한 줄 적는다. 출처 불명(게임·방송 추출)은 쓰지 않는다.
3. 장면에 처음 쓸 때는 등급표 밖이므로 `by_name`이 폴더에서 찾는다. 콘솔 등급은 `-`로 찍힌다. 보고에 «새 소리»라고 적는다.
4. 사장님이 통과시키시면 `실사용.json` «통과»에 이름을 넣고, 3장 단골 표와 `sfx_find.ROLES`에 이름표를 추가한다.
