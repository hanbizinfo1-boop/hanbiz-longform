## 2. 작업 순서 · 멈추는 곳

### 2-1. 장면 하나를 만드는 순서 (애펙 장면, `motion-graphics.md` 1장 1~13)

0. **앞뒤 맥락 먼저** — 앞 30초·뒤 15초 자막과 사장님 편집(확대·컷·**V2 사람 크기**)을 읽고 `기록/작업기록.md` 해당 장면에 «앞/뒤 맥락» 줄. 사장님이 «N분 이후 자르기 조정»을 말씀하시면 그 뒤 장면은 **구간을 다시 잡는다**.
1. **구간 확정** — 자막에서 시작·끝을 찾고 가능하면 **컷 경계**에 맞춘다(클립 가운데면 보고에 «잘라서 바꿔 끼우기»).
2. **단어 시각** — 사장님 컷 조각대로 사람 소리를 이어 붙여 faster-whisper 단어 단위(CPU int8 medium). 받아쓰기 오인식은 기록에 같이. 장면의 모든 움직임은 **그 말이 나오는 단어 시각**에. 자막 글은 받아쓰기가 아니라 **사장님 타임라인·대본 원문**.
3. **화면 확인** — 녹화·사람 프레임을 0.25~0.5초 간격으로 뽑아 마우스 위치·손짓·스크롤 시각을 잰다.
4. **구도 고르기** — «그 말이 실제로 일어나는 자리»(5장 표). 사장님 지시 원문을 기록에.
5. **시안**(사장님이 «시안 추천» 하실 때만 3안) — 방향이 정해지면 묻지 않고 만든다.
6. **그림**(5장 길 고르기) — Codex 는 한 세션에 몰아서(투명 배경·같은 인물은 앞 그림을 `view_image` 로 물림).
7. **조각 → 정지 스토리보드** — PIL 조각을 만들고 **렌더 전에 «다 나온 모습» 정지 화면을 합성해 눈으로 본다**(겹침·글자 깨짐·주소창 노출). 겹침 자동 검사는 렌더 전에 멈춘다.
8. **애펙** — JSX(ASCII) → `AfterFX -r`(감시 `run_ae_guarded`) → `aerender` → ffmpeg. 등장은 `eo`(빠르게 들어와 감속), UI 는 튕김 없음.
9. **효과음** — `sfx-workflow.md`(폴더 주소 1장 · 뜻별 단골 3장 · 순서 4장) → 근거 `sfx.md`. 뜻·그림에 맞는지 먼저, 이름으로 고정, `rule_check.check_sfx` 통과해야 섞는다.
10. **확인** — 렌더 뒤 단어 시각마다 프레임을 모아 보고 ebur128 트루피크. 소리를 귀로 못 들었으면 «못 들었다».
11. **납품 3종 + 폴더 열기** → 12. **점검표**(`checklist.md`) → 13. **기록**(P7).

**장면 연출**
- **앞뒤 맥락 먼저** — 앞 30초·뒤 15초 자막·사장님 편집(확대·컷·배치)을 읽고 기록에 «앞/뒤 맥락» 줄. 앞에서 보여 준 것을 이어받고 뒤 화면으로 자연스럽게 넘긴다. «모든 작업은 무조건 앞뒤 맥락 파악해서 연출하라»(10-07)
- **구도는 그 말이 실제로 일어나는 자리 — 통과 틀 복붙 금지.** 휴대폰·비교 판은 기본값이 아니고 **비교 연출은 연달아 쓰지 않는다**. «왜 핸드폰으로 연출했어, 각 상황에 맞게 연출 구도 잡아야지 · 실제 세팅 페이지에서 설정하는 느낌으로 · 비교 연출도 너무 많으면 안 좋아, 이번엔 다른 연출로»(10-07 08 반려)
- **도형 짜깁기 금지** — 그림은 Codex 이미지·실제 이미지(위키미디어 로고·국기, 녹화 실화면). 알약 단계·점 게이지·도형으로 휴대폰/사물 흉내 금지. 이미지 속 화면 글은 회색 줄·블러 말고 **읽히는 예시 글**. «도형으로 수준 낮은 짜깁기 원하지 않음 · 뭘 물어보고 뭘 대답하는지 예시로 글자로 보이게, 블러 느낌 주지 말고»(10-07 06 반려)
- **화면 글은 말 따라 쓰지 않는다** — 말을 받쳐 주는 개념어·구조로(«심리학적으로 그래요» → «심리학적 요소», «니즈가 굉장히 강해요» → «신청 직후 = 니즈 최고»). «심리학적 요소 이런 식으로 말을 뒷받침하게끔 문맥 구조를 잡아 줘, 말 따라 하지 말고»(10-08 17). **«» 따옴표 대사도 금지** — ««» 이렇게 대본 넣는 거 별로 안 이뻐»(10-08 19). **말을 글로 다시 적어 옆에 띄우지 않는다** — 외부 피드백 «대본으로 설명을 할 것 같으면 위에 굳이 글을 막 적어서 설명했어야 했나? 시선이 분산되는데?»(10-12, 11 왼쪽 위 글) → 글은 단계·개념어 몇 단어만. 숫자·고유 표현은 말에 근거(지어내지 않는다).
- **밋밋하게 두지 않는다** — 캐릭터 표정·말풍선, 글 뜰 때 강조 포인트(반짝 선·테두리 번짐), 커서·타자·카메라. «글자가 생길 때 나오는 포인트들도 없고 … 연출도 없고 해서 몰입이 안 됨»(10-08 13). 의인화 = «Meta» 같은 글자가 적힌 팔다리 달린 인형 캐릭터(좌우 뒤집기 금지), 상황극 = 2D 플랫 캐릭터(같은 인물 이어 씀).
- **인지할 텀 0.6초** — 새 요소는 혼자 0.6초 이상, 같은 종류는 묶음으로, 한 문장에 새 요소 2~3개까지. 빈 구간 규칙 때문에 요소를 끼워 넣지 않는다. «연출이 전체적으로 급해서 정신없는 느낌 · 어떤 거를 보여 줄 때 충분히 인지할 텀은 있어야»(10-07 10)
- **겹침 없음** — 요소끼리·말풍선 꼬리(머리 위 16px)·효과선(머리 반지름 바깥)·사람 PIP·자막 자리 비우기. «말풍선 뾰족한 거 위치가 캐릭터 머리 위에 겹치지 않게 살짝 떨어지게»(10-08 18). 띄운 확대 창과 그림 속 모니터를 선으로 잇지 않는다 — «굳이 … 이어 주지 않아도 사람들 다 저 안에 있는 내용인 거 알아»(21).
- **비교 장면은 쪽마다 색 하나**(빨강 vs 파랑). 그 외는 3색(바탕·글·강조 하나). «웹사이트랑 인스턴트 같이 비교하는 건 색으로 각각 다름을 강조하면 좋을 것 같아»(10-07 06 통과 때)
- **판·카드는 구멍 없이** — 알파 255, 모서리 반경 카드 14 · 이름표·뱃지 12(반투명 190~238·큰 반경 34는 뒤 영상이 비친다, 09-22 디자인 반려).
- **글꼴에 없는 글자** — 새 글 조각은 `tools/glyph_check.py` 로 확인(개구 «·»«→»«①», Noto «▾», 맑은 고딕 «✓✕»·25px 받침 뭉개짐 → UI 글자는 Noto Sans KR 500). «또 깨졌어»(10-08 13)
- **렌더 전에 정지 스토리보드**로 먼저 본다. **영상미**: 등장 4~8프레임 감속·바운스 금지 · 핵심어 하나만 강조색 · 시그니처 모티프 하나(구도는 장면마다 다르게) · 보여 줄 게 그림이면 멈춰 두고 글이면 계속 움직임 · ~~글리치/흔들기는 한 편에 한 번~~ → **흔들림 연출 0번**(10-13, `study/fusion-1013.md` 3장).

**사람·트랙**
- **사람(V2)은 굽지 않는다 — V1 만 렌더**(사람이 반반으로 움직이는 장면만 V3). [A 모드 규칙. B 자동 연출 모드는 완성본이라 사람 층을 프로젝트의 크기·위치·마스크 그대로 다시 쌓는다 — `auto-pipeline.md` 13장] «기존은 네가 V2 를 렌더 안 해서 밑에 마스크가 잘 나왔거든 · V1 부분만 렌더 … 마스크 처리할 게 아니라 기존 작업 로그 읽고 그 워크플로우대로»(10-08 21)
- **강의 컷은 사장님이 확정한다** — 컷·V2/V3·PIP 마스크는 사장님 몫. 나는 확정본 위에 «얹을 것만» XML + 자료. «아닌거같아 지금 내가 제거해서 주는 방향으로하고»(09-23) · «내가 PIP 해볼게»
- **강의 자료는 사장님이 지정한 자막 타이밍에만** — 자막 SRT 를 만들지 않고, 지정 안 한 곳에 넣지 않는다. «내가 원하는 자막타이밍에 네가 에펙이나 영상AI, 코덱스 이미지, 스킬 등으로 자료 만들어주는 방식으로 진행하자»(09-29)
- **강의 자료는 말을 쌓아 정리한다** — 전체화면 카드 말고 인물 옆 보조 패널, 큰 글씨·적게, 말 순서대로 하나씩 쌓기, 비교는 대상 단위. «계속 화면이동이 일어나니까 오히려 정신없어» · «글자는 크게, 작게 하면 의미 없다»(09-23). 미리보기 렌더 없이 XML 만(강의 자료 한정) — «시간 너무 오래 걸려, XML 로 뽑아주면 프리미어에서 확인»
- **강의 포토카드 통과 틀** — 흰 카드·왼쪽 브랜드띠·로고 76px·흰 글자+검은 테두리·노랑은 진짜 강조만. 카드와 같이 나오는 글자는 판에 찍어서(09-30 «나오자마자 글자 떠오르면 급한 느낌»). 새 카드는 `tools/examples/lec12_card01.py` 복사. «오케이 이런 느낌으로»(09-29)
- **무음편집 안전판** — 0.06 VAD 컷 + 말 안쪽 쉼만 안전판(손상 0·사장님 일치 73%), 내용 컷·숨 조각은 마커. «말하는 도중에 자르거나 말이 텀 없이 넘어갈까 봐»(10-02). 절차 `silence-cut.md` 0장.
- **자막은 타임라인 원문** — whisper 받아쓰기 말고 사장님 타임라인/SRT 글 그대로, 위에 같은 말 또 띄우는 중복 자막 금지. «SRT 타임라인에 안 적혀 있어?»(09-28)

**효과음**

- **뜻·그림에 맞춘다** — 조건·기준에 축하음 금지, 도장엔 `도장.mp3`, 게이지엔 차오르는 소리. «천만 원을 벌었다가 아니라 미만인 사람인데 왜 축하 효과음 · 도장에는 왜 도장 효과음 안 쓰고»(10-08 22)
- **자연 길이**(잦아드는 데까지 최대 2.5초, 끝 0.25초 페이드) · 같은 소리 바로 연달아 금지, 번갈아도 3초 안에 같은 파일 3번까지. «효과음 또 짧게 끊기고»(10-07)
- **효과음 브랜드 톤은 실측으로** — 사장님 마감본이 1순위. «만화 계열 빼기»는 폐기(10-02, 뿅 최다). 청음본·A/B 듣기를 요청하지 않는다 — «청음본 들을 시간이없어 … 그냥 실 사용에서 하고»(10-02).

## 5. 길 고르기 — 그림을 어디서 만드나 (`motion-graphics.md` 0장)
