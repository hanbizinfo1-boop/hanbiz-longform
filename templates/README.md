# 템플릿 서랍 — 쓰는 법과 매니페스트 규격

> 자동 연출 파이프라인(`.claude/skills/longform/references/auto-pipeline.md`)의 «③짜기»가 여기서 템플릿을 고르고, «⑤만들기»가 `render.py` 로 렌더한다.
> 템플릿 하나 = 폴더 하나 = `서랍-번호_영문이름/`. 폴더 안 `template.json` 이 매니페스트다. 카탈로그(`카탈로그.md`)와 목록(`registry.json`)은 `python tools/auto/registry.py` 가 만든다 — 손으로 고치지 않는다.

## 1. 서랍

| 코드 | 서랍 | 맡는 것 |
|---|---|---|
| GU | 구성 틀 | 한 편의 뼈대(오프닝·목차·챕터·요약·엔딩 자리와 서랍별 비중) |
| CA | 카메라 | 녹화·풀샷 확대·축소·밀기·따라가기 |
| EM | 강조 | 말 위 짧은 강조(1~8초) |
| SC | 장면 | «그 말이 실제로 일어나는 자리» 연출(5~30초) |
| TR | 전환·표지 | 챕터 표지·목차 복귀·섹션 끊기 |
| OE | 오프닝·엔딩 | 로고 오프닝·요약·CTA·로고 엔딩 |
| SD | 소리 | 효과음 역할표·BGM(오더 시) |
| TN | 느낌 | 서랍별 가중치·밀도·색·모티프 묶음 (`tones/`) |

## 2. `template.json` 필드

| 필드 | 뜻 | 예 |
|---|---|---|
| `id` · `name` · `drawer` · `version` | 이름표. 번호는 한번 붙이면 안 바꾼다 | `"CA-03"` · `"녹화따라줌"` · `"CA"` · `1` |
| `status` | `통과`(사장님 통과 이력) · `대기`(만들었으나 반응 없음) · `시안` · `신규` | `"통과"` |
| `engine` | `ae` · `html` · `pil` · `design` · `blender` · `aivideo` · `compose`(합성기가 직접) | |
| `subject` | **연출 주체** — 화면에서 무엇이 주인공으로 움직이나(하나 또는 둘): `사람` · `녹화화면` · `글자` · `자료이미지` · `캐릭터` · `데이터` · `무대배경` · `브랜드` · `소리` | `["녹화화면"]` |
| `source_ref` | 이 연출을 어디서 배웠나 — 통과 장면 번호 · 레퍼런스(유튜버·영상 제목·링크·노트 경로) | `["빡이사DB 13", "study/typography-remotion.md T2"]` |
| `summary` | 한 줄로 무엇을 하나 | |
| `use_when` / `avoid_when` | 상황 태그(아래 3장) | |
| `tones` | 느낌별 가중치 0~1 (`TN-1`~`TN-4`) — 안 적으면 0.5 | `{"TN-4": 1.0, "TN-3": 0.2}` |
| `screens` | 쓸 수 있는 원문 화면 상태: `PIP`(사람 30%) · `풀샷`(사람 50%) · `사람없음` | |
| `layer` | `L1`(녹화) · `L2`(V1 바꿔 끼우기) · `L4`(알파 얹기) · `L5`(표지·앞뒤) · `audio` | |
| `moves_person` | 사람 층(L3)을 옮기는가(반반 등) | `false` |
| `duration` | 초 [최소, 최대] | `[2, 20]` |
| `slots` | 입력 칸. 종류 `text` · `image` · `box`(화면 좌표 상자) · `words`(단어 시각 목록) · `number` · `choice` | 4장 |
| `drawn_allowed` | **코드로 그려도 되는 디자인 요소만** 적는다(5장) | `["테두리", "카드바탕"]` |
| `keepout` | 비울 자리: `사람PIP` · `자막띠` · `얼굴+16px` · `판밖` | |
| `timeline` | 움직임 시간표 — 6장 | |
| `look` | 색·글꼴·크기·반경 등 고정값(근거 있는 값만) | |
| `sfx` | `[{ "at": "...", "role": "역할", "meaning": "긍정/부정/중립" }]` — 역할은 `sfx-workflow.md` 3장 단골 이름 | |
| `rules` | 이 템플릿에서 꼭 지킬 것 — 줄마다 끝에 근거(사장님 날짜·문서) | |
| `rejected` | 이 결로 반려된 이력(사장님 원문) — 다시 하지 않을 것 | |
| `sample` | 견본 렌더용 일반 입력값(실제 업체·개인정보 없음) | |
| `fallback` | 실패하거나 못 쓸 때 대신 쓸 템플릿 ID 1~2개 | |
| `from` · `basis` | 출처 코드 경로 · 근거 문서 장 | |
| `todo` | 렌더 코드를 만들기 전에 정해야 할 것 · 확인 안 된 값 | |

**숫자 규칙**: `look`·`timeline` 의 숫자는 근거(통과 장면 코드·실측 문서)가 있는 값만 쓴다. 근거가 없으면 값 옆 `todo` 에 «초기값 — 첫 견본에서 정함»이라고 적는다. 지어낸 «실측»은 금지.

## 2-1. 세 갈래로 찾는다

카탈로그는 같은 템플릿을 **단계(서랍)별 · 연출 주체별 · 도구(engine)별** 세 표로 보여 준다(사장님 10-08 «각 단계별로 또 각 연출주체별로 또 도구별»).

## 3. 상황 태그 (use_when / avoid_when 에 이 말만 쓴다)

`설정·버튼` · `화면 속 특정 부분` · `개념 비교` · `과정·단계` · `보는 사람 시점` · `일상 상황` · `현실 공간·사람` · `정리·목차` · `숫자·금액` · `용어 제시` · `질문` · `경고·실수` · `사례·후기` · `알고리즘·시스템 행동` · `소개·여러 항목` · `결론·센 말` · `챕터 시작` · `챕터 끝` · `한 편 시작` · `한 편 끝` · `자료 등장`(외부 자료·캡처·기사·후기를 띄움) · `브랜드` · `감정·리액션` · `가림`(업체·개인정보 노출 구간)

상황 태그는 상황 강령(`.claude/skills/longform/references/situation-playbook.md` PB-01~18)의 판별 신호와 짝이다.

강의 6유형(`lecture-graphics.md` 2장): `용어 제시` · `리스트`(=소개·여러 항목) · `부연` · `정의·조건` · `수식` · `질문` 도 그대로 쓴다.

## 4. 이미지 칸 — 도형 흉내 금지의 핵심

```json
"photo": {"kind": "image", "source": ["codex", "crawl"], "style": "실사 사진", "alpha": false, "desc": "무엇이 찍힌 사진인가"}
```
- `source` 는 이것만: `doc`(자료 원본 — 사장님이 준 PDF·공고문·공식 공개 문서의 페이지 이미지) · `codex` · `crawl`(공식·위키미디어, 출처 필수) · `real_capture`(녹화 실화면 크롭) · `brand`(`소재/브랜드` 로고 원본) · `char2d`(Codex 투명 배경 캐릭터) · `render3d`(블렌더) · `aivideo`(유료, 한도 안).
- 휴대폰·사람·건물·서류·도장·아이콘·로고처럼 **«사물»은 반드시 이미지 칸**이다.
- `style`: `실사 사진`(사람 나오면 항상 «사진기로 찍은 사진» 톤, `ai-video.md` 3장) · `2D 플랫` · `3D 비닐` · `손글씨 종이` 중 하나 — 한 편 안에서 섞지 않는다.

## 5. 코드로 그려도 되는 것 (`drawn_allowed` 에 쓸 수 있는 말)

`카드바탕` · `판` · `구분선` · `테두리` · `밑줄` · `타원테두리` · `형광펜` · `말풍선바탕` · `효과선` · `반짝선` · `테두리번짐` · `빛훑기` · `어둡게덮기` · `UI위젯`(버튼·입력칸·진행선·스위치·캐럿·커서 — UI 그 자체) · `HUD`(괄호·라벨·진행 눈금) · `차트`(축·막대·선·원 — 데이터 시각화 자체, **실제 수치만**) · `글자`

이 목록 밖의 것을 `drawn_allowed` 에 적으면 `registry.py` 가 등록을 거절한다(예: «휴대폰모형», «아이콘», «사람실루엣»).

## 6. `timeline` 쓰는 법

```json
"timeline": [
  {"at": "t0",            "do": "녹화 확대 시작", "to": "zoom", "dur": 0.5, "ease": "ez"},
  {"at": "word:target",   "do": "테두리 그리기",   "dur": 0.25, "ease": "eo"},
  {"at": "t1-0.45",       "do": "원위치",          "dur": 0.45, "ease": "ez"}
]
```
- `at`: `t0`(박자 시작) · `t1`(끝) · `t0+0.6` 같은 더하기 · `word:<slot>`(그 칸 단어의 시각) · `word:<slot>[i]`(목록 i번째).
- `ease`: `eo`(빠르게 들어와 감속 — 등장 기본) · `ez`(양쪽 감속 — 카메라) · `lin` · `hold`. 튕김(오버슈트)은 UI·카드·글자에 쓰지 않는다(캐릭터 눌림만 예외).
- 등장은 4~8프레임(59.94fps 기준 0.07~0.13초)부터 0.22초 사이, 새 요소는 혼자 0.6초 이상(인지할 텀).

## 7. 상태가 바뀌는 길

`신규` → 견본 렌더 → `시안` → 실전 첫 사용 → `대기` → 사장님 «통과» → `통과` (반려되면 `rejected` 에 원문, 같은 이유 2번이면 `avoid_when` 에 그 상황).

## 8. 설계 결정 기록 (설계자 10-08)

- **상태 «통과»는 롱폼 가로에서 사장님이 통과시킨 것만.** 분양 쇼츠·세로에서 통과한 연출을 옮긴 템플릿은 «대기»(실사용 이력 있음) 또는 «신규».
- **캐릭터 스타일은 한 편에 하나**(2D 플랫 또는 3D 비닐 인형). 실사 사진 자료(Codex 실사·녹화·문서)와는 같은 편에 섞어도 된다 — 4장 «한 편 안에서 섞지 않는다»는 캐릭터·일러스트 결을 말한다.
- **사장님 통과 값이 학습분 원칙보다 이긴다**: EM-07 포토카드 결론 «쾅»(170→94→103→100)은 6장 튕김 금지의 예외(12강 통과).
- **자동 연출 모드에서는 실제 업체·개인정보가 보이는 실자료를 쓰지 않는다**(블러로 가려도) — 재현·Codex 로. 사장님이 그 자료를 지정한 건만 예외.
- 서랍별 길이(1-1장)는 안내값이다. 실측 통과 길이가 벗어나면 실측을 따른다(EM-03 5~35초).
